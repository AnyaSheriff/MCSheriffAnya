# Броня и боевые зачарования Java 26.3

Следующая ограниченная партия после [щитов и брони](defense-26.3.md).
Цель Ани — полный игровой процесс. Восемь случаев не означают полные B06/B07
или долю всех механик Minecraft. Ниже сохранён неуспешный baseline и свежая проверка исправлений.

Первый baseline использовал проверенный runtime95cc96ede44ca351c24b614a72701c189a20e62d,
native CI42197003218, SHA256
`bfccaad288f826e4ee9e17be8e95fb7ebf02775b4380bcc12d6cf68d71cf5b84`.
Новые игровые записи запускаются на GitHub отдельным workflow без сборки.
Исходники чужих ядер/библиотек/оригинала не используются: официальный JAR
работает как непрозрачная программа, протокол — ранее закреплённые JSON26.3.

## Критерии до исходов — v1

Состав — `tools/blackbox/ci/armor-enchants-777.json`. Шесть native-копий прежних
сценариев сохраняют экипировку, действия и случайные допуски; убраны только
legacy `!syncattrs`/attr_phase. Нативная наблюдаемая phase_alignment=all сохранена.
Два новых случая экипируют железный нагрудник внутри записи, до первого удара:
износ200→201→202, либо239→поломка→второй удар без нагрудника. Сверяются настоящие
update_health, источники/владельцы урона, слоты, событие поломки и компоненты вещи.

SharpnessV: HP10; StrengthII: HP7; WeaknessI: HP17 и истечение эффекта;
ResistanceII: два принятых удара с уменьшением урона. FireAspectI: обычный
удар мечом, реальный урон огня, флаг горения и погасания у обоих наблюдателей.
ThornsVII — отдельный принудительный контроль срабатывания (не естественный
уровень выживания): настоящий обратный владелец, случайный урон1..5, износ3.
Шанс обычных ThornsIII этим не проверяется; нужны отдельные статистические записи.
Начальные20HP каждого участника обязательны с исходным update_health до действий.

Прежние compare.js/bot.js и их допуски не меняются. Дополнительные wire-контроли
могут только запретить успех. Неудачи сохраняются; новое правило после наблюдения
не превращает старый FAIL в PASS. Точные даты/исходники/хеши и raw будут приложены
после записи. Полный72-сценарный перечень пока не оценён.
