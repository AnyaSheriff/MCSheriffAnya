# Серверные моды: первый собственный API

Для ядра **Minecraft 26.3 / protocol 777** подготовлен небольшой собственный
исходный ModSDK. Он переводит самостоятельно написанный Java source-subset в
WASM-компонент существующей песочницы ядра. Доступны регистрация запуска/выгрузки,
входа/выхода игрока и периодической задачи, журнал, личное сообщение и рассылка.

Это не загрузчик Fabric/Forge и не автоматический перенос их JAR. Моды 1.21.1,
клиентские изменения, новые блоки/предметы, Mixin и произвольный Java-код этим
срезом не поддерживаются. Программа полностью отклоняет неизвестный код и лишние
файлы; русский отчёт указывает причину и место. Для переноса разработчик должен
сам адаптировать поддерживаемую серверную логику к нашему API.

Собственный пример: [Welcome.java](../tools/mod-api/fixtures/welcome/Welcome.java).
Точный язык, ограничения, сборка и проверки:
[tools/mod-translator/README.md](../tools/mod-translator/README.md).
Новые привилегии не выдаются: используются те же ограничения Wasmtime, что и
для обычных плагинов. Формат установки тоже прежний — `plugins/<name>/`.
