# Проверка гипотезы процедурных слоёв End26.3

Предыдущий ограниченный банк E отклонён; его не расширяли под два семени.
Здесь проверяется только гипотеза геометрии отдельных слоёв и видимых переходов.
Основной генератор и CI не менялись, production-принятие не заявляется.

## Что было заморожено до наблюдения

Гипотеза использует целое `q=2R`, `q=1..12`:

```
|dx|, |dz| <= ceil(q/2)
4*(dx²+dz²) <= (q+2)²
```

Начальный q входит в 8/10/12. Между видимыми слоями q уменьшается на 1 либо3.
Checker сохраняет все совместимые состояния и последовательности; маска9клеток
не различает q1/q2. Правило остановки намеренно не проверяется. Вероятности
шагов, внутренний RNG и веса ширины неизвестны и не назначались.

На development-наборе32прежних постановок гипотеза воспроизводила160слоёв.
Этот набор уже использовался для её построения и не называется слепым контролем.
До новой серии зафиксированы [гипотеза](../testdata/world-profile/genaudit-26.3/end-island-procedural-hypothesis.json),
[план](../testdata/world-profile/genaudit-26.3/end-island-procedural-heldout-plan.json),

## Новый заранее выбранный контроль

Seed2026102803,32постановки `minecraft:end_island` наY120 в свежем flatvoidOverworld,
сетка с шагом32. Это прямой изолированный вызов feature, а не естественное
размещение в Энде. JAR только запускался и хешировался; его содержимое не изучалось.
Весь lifecycle проходил под общим flock; отдельные TCP26386/UDP26387,
Java25/Xmx1G/2CPU,153forceloadчанка. Рабочий лимит100с, watchdogTERM110/KILL115с,
общий предел120с; останавливается только собственная группа процесса.

| Проверка | Development | Новый контроль |
|---|---:|---:|
| Постановки |32|32|
| Наблюдённые слои |160|154|
| Формы без несовпадений клеток/последовательности |32|32|

Новая серия завершилась за18.136с, exit0; оба порта свободны, watchdog не понадобился.
Независимо перечитаны153/153сохранённых чанка:9798клеток end_stone совпали,
посторонних клеток и обрезанных окон нет. Одна новая форма имеет8слоёв:
старый наблюдённый максимум7 не оказался пределом. Checker не ограничивал
толщину этим прежним максимумом и прошёл её без изменения.

**Замороженная гипотеза прошла новый контроль без подгонки.** Это подтверждение
конечного семейства масок и возможности видимых переходов; оно не устанавливает
точную формулу игры, stop-условие, RNG или распределение форм. Новые клетки
сохранены как контрольные наблюдения, а не добавлены в банк E.

## Повтор без Minecraft

Из корня репозитория:

```
python -m unittest discover -s tools/measure -p test_genaudit_263_end_geometry.py -v
python tools/measure/genaudit_263_end_geometry.py \
  --hypothesis testdata/world-profile/genaudit-26.3/end-island-procedural-hypothesis.json \
  --observations testdata/world-profile/genaudit-26.3/end-island-procedural-heldout-cells.json \
  --output /tmp/end-procedural-heldout-validation.json
```

Шесть Pythonтестов проверяют прежние клетки, неверные переходы при допустимых
масках, границы, дырки/дубликаты, неполные серии и отсутствие выдуманного stop-лимита.
Следующий отдельный вопрос — как обоснованно завершать последовательность и
выбирать шаги. Этот опыт сам по себе не разрешает назначить им веса, включить
новый генератор в production или заявить полный переход на26.3.
