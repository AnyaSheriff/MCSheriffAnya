# Цвета чата и консоли

Цвета работают в обычном чате, `/say`, ответах команд и текстовых сообщениях
плагинов. JSON-компоненты `/tellraw` сохраняют собственное оформление.

```text
&aЗелёный текст
&c&lКрасный жирный&r снова обычный
&#FFAA00Произвольный RGB-цвет
&&aБуквальная надпись &a, без смены цвета
```

`&&` выводит один буквальный `&`. Неизвестные коды вроде `&z` остаются текстом.
Поддерживаются регистры `&a`/`&A`, запись `§a` в серверных сообщениях и
развёрнутый HEX `&x&F&F&A&A&0&0` / `§x§F§F§A§A§0§0`. Обычный Java-клиент
не вводит знак `§` в чат; используйте `&`.

| Код | Цвет / оформление |
|---|---|
| `&0` / `&1` / `&2` / `&3` | Чёрный / тёмно-синий / тёмно-зелёный / тёмно-бирюзовый |
| `&4` / `&5` / `&6` / `&7` | Тёмно-красный / пурпурный / золотой / серый |
| `&8` / `&9` / `&a` / `&b` | Тёмно-серый / синий / зелёный / бирюзовый |
| `&c` / `&d` / `&e` / `&f` | Красный / розовый / жёлтый / белый |
| `&l` / `&o` | Жирный / курсив |
| `&n` / `&m` | Подчёркнутый / зачёркнутый |
| `&k` | Перемешанные символы в игре |
| `&r` | Сброс цвета и всех стилей |

Новый цвет сбрасывает прежние стили: для жирного зелёного пишите `&a&l`.
Java получает компоненты текста с точным RGB. Bedrock получает ближайший
цвет стандартной палитры; подчёркивание и зачёркивание там опускаются, поскольку
коды `§m`/`§n` у Bedrock означают другие цвета. Консоль не перемешивает символы
от `&k`, чтобы сообщения оставались читаемыми.

## Консоль и панель хостинга

В `config/mcsa.properties`:

```properties
console-colors=auto
```

- `auto`: цвета в терминале; при перенаправлении вывода в файл — чистый текст.
  Непустая переменная `NO_COLOR` и `TERM=dumb` отключают автоматический цвет.
- `always`: цвета также через pipe — для панели хостинга, поддерживающей ANSI.
  Этот явный выбор имеет приоритет над `NO_COLOR` и `TERM`.
- `never`: без цветового оформления консоли. Цвета игрового чата сохраняются.

Для Hosting-Minecraft / Pterodactyl / Pelican поставьте `console-colors=always`
и перезапустите ядро. Поддержка отображения ANSI зависит от самой панели.
Не меняйте настройки Java `.jar`: цвет формирует Rust-ядро.

INFO выделяется зелёным, WARN жёлтым, ERROR красным, DEBUG серым. После сообщения
цвет сбрасывается до перерисовки строки ввода. Отчёты об ошибках сохраняются без
цветовых кодов. В `auto`/`never` файл перенаправленного stdout также чистый;
`always` намеренно сохраняет ANSI в stdout, даже если записать его в файл.

Проверка через консоль:

```text
say &a&lЦвета работают&r — обычный текст
say &#12ABEFHEX-цвет
```

## Проверка разработчика

`python3 tools/colors/smoke.py --binary /путь/к/mcsheriffanya` запускает временные
серверы на 127.0.0.1:26005. Наш небольшой Java-клиент проверяет реальный NBT
чата, форматирование, HEX, сброс стилей, Unicode и экранирование. Отдельные
запуски проверяют pipe/PTY, auto/always/never, NO_COLOR и TERM=dumb. Это проверка
байтов протокола и терминала; ручная проверка шрифтов конкретного клиента/
панели выполняется отдельно.
