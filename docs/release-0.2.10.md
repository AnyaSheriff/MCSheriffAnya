# MCSheriffAnya 0.2.10-alpha

Основная игра — Java Edition 26.3, протокол 777. Эта версия собирает изменения
после 0.2.9-alpha; полный игровой процесс и полный паритет с оригиналом пока
не заявлены. Точные границы проверок: [готовность игрового процесса](gameplay-readiness.md).

## Основные изменения

- Переход на основную Java 26.3, запуск без мастера настройки. При первом старте
  показывается уведомление об анонимных отчётах; настройка отключения сохранена.
- Исправления сохранения инвентаря, боя, щитов, снарядов, износа брони и зачарований.
  Последняя партия проверяет обычные «Шипы III» и исключает отражение от брони,
  уже разрушенной входящим ударом при «Прочности III».
- Сон пустого сервера и пробуждение от консольных команд. Отдельные тики блоков
  измерений доступны как эксперимент: выключены по умолчанию, не распараллеливают
  сущности, жидкости и TNT; ускорение всех серверных задач не обещается.
- Самостоятельное приложение Android 7+: ARMv7/ARM64, настройки, темы, консоль,
  онлайн/TPS/ресурсы, ZIP-копии через системный выбор файла, подписанные обновления
  ядра без переустановки APK. Обновление самого интерфейса требует нового APK.
- Android 0.2.3-preview/code5: палитра применяется после выбора темы AppCompat;
  для Samsung Android 14+ используются исходные системные оттенки, чтобы обойти
  голубые цвета из несогласованных `system_primary_*`.
- В релизе предусмотрены готовые бинарники и архивы для Linux x86_64/ARM64,
  Windows x86_64 и macOS ARM64/Intel, а также отдельный Android ARM64 для Termux.

## Обновление

Сначала остановите сервер и сохраните отдельную копию мира, конфигов и БД.
Старые миры 26.1.2 требуют явной миграции по
[инструкции перехода мира](world-version-transitions.md); смена бинарника не
превращает старый мир в мир другой версии автоматически.

На Android устанавливайте новый APK поверх прежнего: имя пакета и локальная
подпись остаются прежними. Не удаляйте приложение ради обновления — удаление
стирает приватные данные. Пользовательские APK подписаны прежним локальным
ключом; временные APK из GitHub Actions предназначены для тестов.

Подписанное обновление ядра требует остановки сервера и подтверждения, создаёт
ZIP данных и проверяет подпись, SHA256 и архитектуру. Возврат ядра не откатывает
мир: старый мир восстанавливается отдельно из ZIP.

## Ограничения

Совместимость старых Java-клиентов частичная, полный диапазон 1.12.2–26.3
не обещается. Bedrock также остаётся частичным. Подробности:
[версии Java](java-multiversion.md), [Android](../android/README.md).
Проверки x86_64 в эмуляторах не заменяют испытаний ARM на настоящем телефоне,
долгой работы с погашенным экраном и расхода батареи.
