# Проверка готовности основного игрового процесса

По уточнению Ани от6ноября цель — полный игровой процесс, с обязательными
механиками в приоритете; прежний промежуточный ориентир был не менее90%.
Сейчас процент **не измерен**. Полное прохождение рабочего перечня ниже
не означает проверку абсолютно всех механик и комбинаций Minecraft.
Число тестов, обработанных пакетов или зарегистрированных предметов не является
процентом готовности игры.

Рабочая [редакция перечня](gameplay-scenarios.md) содержит **72 сценария
в девяти группах**, с приоритетом обязательного PvP, выживания и сохранности
данных. Полная оценка по этому перечню ещё не проведена. Непроверенный статус
не означает, что механика не работает; прежние свидетельства остаются
действительными для своих сборок и проверенного объёма.

## Обязательная часть

| Группа | Что проверяется обычными действиями |
|---|---|
| Вход и сохранение | Первый запуск, выбранная версия, вход, выход, повторный вход, перезапуск, сохранение мира и игрока |
| Бой | Урон, задержка атаки, крит, взмах, отбрасывание, щит, броня, снаряды, зачарования |
| Выживание | Здоровье, голод, насыщение, лечение, эффекты, падение, огонь, вода, смерть и возрождение |
| Инвентарь | Подбор, выбрасывание, перенос, разделение, быстрый перенос, курсор, экипировка, отсутствие дюпов |
| Добыча и строительство | Скорость разрушения, нужный инструмент, прочность, добыча, размещение, ориентация, жидкости |
| Крафт и станции | Сетка 2×2/3×3, книга рецептов, печи, сундуки, наковальня, зачарование, зельеварение, торговля |
| Мобы | Появление, движение без зацикливания, поиск пути, атака, бегство, размножение, приручение, дроп |
| Мир | Загрузка чанков, освещение, время, погода, рост, порталы, измерения, восстановление после перезапуска |
| Версии | Те же действия через поддерживаемых клиентов; отсутствие потери предметов и повреждения мира |

## Как считать

Перед подсчётом фиксируются редакция перечня, сборка, основной игровой профиль
и обязательные клиенты. Целевой основной профиль — **26.3**; 26.2 входит
только в клиентскую совместимость. Контрольные результаты профиля26.1.2
не доказывают готовность правил26.3. Клиентская матрица указана в перечне.

Каждый сценарий имеет ожидаемый результат, точные версии и SHA сборки,
запись официального сервера, запись ядра и итог сравнения. Допустимые различия
по тактам и критерии случайных исходов задаются до записи.
Сценарий засчитывается только при проверенном поведении и сохранении данных;
частичная реализация или проверка только собственного кода не считается готовой.
Обязательные варианты внутри одной строки не увеличивают число баллов:
непройденный вариант оставляет всю строку незачтённой.

Процент — число прошедших сценариев к числу всех сценариев закреплённого списка.
Список и его изменения публикуются вместе с результатом; нельзя уменьшать его,
чтобы повысить показатель. Результат дополняется числом прошедших в каждой группе.
Критические ошибки обязательной части (дюп, потеря мира, сломанный бой, невозможный
вход) блокируют заявление о готовности независимо от общего процента.

Исторические результаты помечаются `previous build` и не переносятся на новые
профили автоматически. Границы охвата основного перечня публикуются вместе
с результатом: такой показатель нельзя называть долей всех механик Minecraft.

Новый контент 26.3 учитывается по [отдельному перечню](java-26.3-content.md).
Косметические удобства не должны вытеснять обязательные сценарии.


Выбранные боевые проверки на сборке `b613b967` от 7 ноября 2026 описаны в
[партии Fire Protection и Thorns](protection-edges-26.3.md): 33 сценария,
66 свежих записей обеих сторон и независимый повторный анализ. Это ограниченное
подмножество боевых случаев; полные строки B06/B07 ещё не зачтены, процент
по рабочему перечню из 72 сценариев пока не измерен.

8ноября добавлена [проверка обычных ThornsIII и поломки с UnbreakingIII](thorns-natural-26.3.md):
заранее заданная выборка, оба наблюдателя, реальные HP/Slot/износ и отдельная
регрессия отражения после разрушения нагрудника. Это также узкая часть B06/B07,
без пересчёта общей готовности и без утверждения о полном RNG/PvP.
