# Проверка готовности основного игрового процесса

По решению Ани после текущей миграции цель — не менее90% игрового процесса,
с обязательными механиками в приоритете. Сейчас процент **не измерен**.
Число тестов, обработанных пакетов или зарегистрированных предметов не является
процентом готовности игры.

## Обязательная часть

| Группа | Что проверяется обычными действиями |
|---|---|
| Вход и сохранение | Первый запуск, выбранная версия, вход, выход, повторный вход, перезапуск, сохранение мира и игрока |
| Бой | Урон, задержка атаки, крит, взмах, отбрасывание, щит, броня, снаряды, зачарования |
| Выживание | Здоровье, голод, насыщение, лечение, эффекты, падение, огонь, вода, смерть и возрождение |
| Инвентарь | Подбор, выбрасывание, перенос, разделение, быстрый перенос, курсор, экипировка, отсутствие дюпов |
| Добыча и строительство | Скорость разрушения, нужный инструмент, прочность, добыча, размещение, ориентация, жидкости |
| Крафт и станции | Сетка2×2/3×3, книга рецептов, печи, сундуки, наковальня, зачарование, зельеварение, торговля |
| Мобы | Появление, движение без зацикливания, поиск пути, атака, бегство, размножение, приручение, дроп |
| Мир | Загрузка чанков, освещение, время, погода, рост, порталы, измерения, восстановление после перезапуска |
| Версии | Те же действия через поддерживаемых клиентов; отсутствие потери предметов и повреждения мира |

## Как считать

Перед подсчётом фиксируется перечень отдельных сценариев внутри каждой группы.
Каждый сценарий имеет ожидаемый результат, версию, запись официального сервера,
запись ядра и итог сравнения. Допустимые различия по тактам указываются отдельно.
Сценарий засчитывается только при проверенном поведении и сохранении данных;
частичная реализация или проверка только собственного кода не считается готовой.

Процент — число прошедших сценариев к числу всех сценариев закреплённого списка.
Список и его изменения публикуются вместе с результатом; нельзя уменьшать его,
чтобы повысить показатель. Результат дополняется числом прошедших в каждой группе.
Критические ошибки обязательной части (дюп, потеря мира, сломанный бой, невозможный
вход) блокируют заявление о готовности независимо от общего процента.

Новый контент26.3 учитывается по [отдельному перечню](java-26.3-content.md).
Косметические удобства не должны вытеснять обязательные сценарии.
