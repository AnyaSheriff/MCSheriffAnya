# Раздельная проверка внешних островов Энда

Диагностический опыт после третьей переписи, не изменение основного генератора.
На стандартных GitHub runners собираются четыре временных варианта одного
коммита. В каждом меняется только `src/world/the_end.rs`:

| Вариант | Внешний шум | Отдельные маленькие островки |
|---|---|---|
| A | Текущий E3 | Включены |
| B | Текущий E3 | Выключены |
| C | До E3: 5/2 октавы, вес 0,3 | Включены |
| D | До E3: 5/2 октавы, вес 0,3 | Выключены |

У старого шума также убирается множитель 28/31. Выключение маленьких островков
действует одновременно на запрос высоты и запись чанка через общий метод.
Кайма главного острова, биомы, хорус, города и шлюзы сохраняются. Вариант D
поэтому не равен полному откату E3.

На каждый вариант и каждое из двух исходных семян создаётся 2803 чанка Энда:
центральное окно `[-12,-12,12,12]` и внешние окна `[112,112,144,144]`,
`[-144,112,-112,144]`. Всего восемь измерений, 22424 пары чанков.
Обычный мир и Незер не включены в перепись; запуск сервера создаёт только
необходимые начальные данные обычного мира.

Официальная статистика берётся из неизменного `ci-reference-pass2.json.gz`.
Контроль A должен точно воспроизвести End-строки третьей переписи из
`end-control-pass3.json.gz`. Сами анализатор, эталон и допуски не меняются.
Строка расстояния между спавнами исключается, поскольку не относится к Энду.

Для каждого варианта отдельно сохраняются SHA коммита, исходного и изменённого
файла, описания замены, бинарника, соответствующего helper, Cargo.lock,
исходного и производного планов. Helper собирается заново из того же варианта.
Миры остаются на runner; в артефакты попадают бинарники, логи и компактные отчёты,
хранящиеся три дня. Официальный сервер и игровые архивы в опыт не входят.

Проверки перед выводами:

- Все восемь измерений содержат ровно 2803 ожидаемых чанка без пропусков.
- A воспроизводит контрольные метрики обоих семян.
- SHA высот всех 625 центральных чанков одинаков для A/B/C/D на каждом семени.
- Скачки отдельно разбиты на суша–пустота/суша–суша и границы/внутренность.
- Эффекты островков: A−B и C−D; эффекты шума: A−C и B−D. Их разница
  показывает взаимодействие факторов.
- Новые и исчезнувшие строки, новые выходы за допуск и все ухудшения
  сохраняются отдельно. Одно улучшенное число не делает вариант исправлением.

Запуск: push инструментов в `wip/end-ablation-*` запускает
`.github/workflows/end-ablation.yml`. Основная рабочая ветка при этом
не меняет алгоритм генерации. Любое будущее исправление требует обычных
Rust-проверок и отдельной сверки поведения.

## Результат четырёх вариантов

[Run 40644442462](https://github.com/AnyaSheriff/MCSheriffAnya/actions/runs/40644442462)
на `eb5736d73c5c129208a699f177e0b17d2bbf3f54` завершился успешно.
Все 22424 пары проверены; контроль A воспроизвёл третью перепись.
Центральные высоты совпали между четырьмя вариантами для каждого семени.
[Сводка, контрольные суммы и разложение скачков](../testdata/world-profile/genaudit-26.3/end-factorial-results.json).

| Вариант | Вне допуска: владелец / второе | Новых выходов: владелец / второе |
|---|---:|---:|
| A | 16 / 36 | 0 / 0 |
| B | 22 / 38 | 6 / 3 |
| C | 14 / 38 | 0 / 2 |
| D | 19 / 36 | 5 / 1 |

У C/D на втором семени добавились две строки внутри допуска; они не считаются
исправлениями. Старый шум увеличил число границ суши с пустотой на обоих
семенах. Отключение маленьких островков убрало редкие скачки внутри суши,
но ухудшило другие показатели. Ни один из B/C/D не принят в генератор.
Полные отчёты скачаны локально и пересчитаны исходным анализатором. Сырые миры
с runners не скачивались: контрольные суммы центральных высот сопоставлены
по сохранённым результатам проверенной программы измерений.

## Вариант E: наблюдённые формы островков

Отдельный короткий опыт на официальном сервере 26.3 создал 32 `end_island`
командой `place feature` на Y120 в пустом плоском обычном мире без опор.
Все 32 объекта подтверждены чтением сохранённых блоков: 9532 блока,
128 проверенных чанков, без пропусков и обрезаний.

У наблюдений верхние площадки содержат 77/109/145 блоков вместо наших
49/81/113. Наблюдённая толщина — 3–7 слоёв; прежняя формула даёт 4–6.
Ни один из 32 объектов не совпал с прежней формулой. Одинаковая ширина
может иметь разную толщину. Это измерение геометрии, а не частоты естественной
генерации или выбора форм внутри каждого класса.

E временно заменяет только геометрию маленьких островков на эти измеренные
формы. Последовательность выбора координат, высоты и класса ширины сохраняется.
Форма выбирается отдельным потоком, поэтому не сдвигает второй островок.
Таблица однократно превращается в плотные массивы 13×13; каждый запрос
столбца обращается прямо к одной клетке.

[Столбцы моделей](../testdata/world-profile/genaudit-26.3/end-island-shapes-26.3.json)
проверяются против [отдельно сохранённых клеток и слоёв](../testdata/world-profile/genaudit-26.3/end-island-shapes-observations-26.3.json).
Радиусы 4/5/6 представлены 10/14/8 формами. Четыре Rust-теста проверяют точное
восстановление всех наблюдений, непрерывность, отрицательные границы четырёх
чанков и некорректные входы. Их фактический запуск входит в CI варианта E.

Текущая матрица workflow — A/E на двух семенах. E остаётся экспериментом:
модуль форм не подключён к основному `the_end.rs`. Принятие зависит от
результатов измерений и проверок; совпадение изолированных форм не означает
полного совпадения естественного Энда.

### Результат A/E

[Run 40649990757](https://github.com/AnyaSheriff/MCSheriffAnya/actions/runs/40649990757)
на `40387b93c5b4ed8c79e3f49f6a4a7a2bf8cb4bfb` прошёл. Проверены 11212 пар,
SHA трёх входов моделей, обоих бинарников и helpers; A повторил контроль,
центральные высоты A/E одинаковы для каждого семени. Четыре Rust-теста форм
и по 20 Python-проверок на runner успешны. Все 32 формы дополнительно
восстановлены из столбцов и сверены с сохранёнными клетками. Автор отдельно
перечитал официальный регион: совпали все 9532 блока, 128 чанков без пропусков.

| Показатель E относительно A | Владелец | Второе семя |
|---|---:|---:|
| Вне допуска, было → стало | 16 → 16 | 36 → 36 |
| Новых выходов за допуск | 0 | 0 |
| Улучшившихся строк | 9 | 40 |
| Ухудшившихся строк | 39 | 30 |
| Скачки внутри внешней суши, было → стало | 38 → 42 | 50 → 53 |

Имеются улучшения p95 высоты малых островов, но доли перепадов на границах
на обоих семенах отдалились от оригинала. Нулевая разница числа строк вне
допуска не означает отсутствия ухудшений.
[Все изменившиеся показатели и проверка](../testdata/world-profile/genaudit-26.3/end-measured-shapes-results.json).

**E не включён в основной генератор.** Изолированная геометрия подтверждена,
но естественные места появления, перекрытия и распределение форм требуют
отдельного измерения. Простое расширение островков пока не даёт основания
утверждать улучшение Энда целиком. Следующий шаг — разбор естественных
изолированных островков в сохранённых официальных мирах с явным учётом
обрезанных и соединённых объектов.
