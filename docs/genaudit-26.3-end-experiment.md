# Раздельная проверка внешних островов Энда

Диагностический опыт после третьей переписи, не изменение основного генератора.
На стандартных GitHub runners собираются четыре временных варианта одного
коммита. В каждом меняется только `src/world/the_end.rs`:

| Вариант | Внешний шум | Отдельные маленькие островки |
|---|---|---|
| A | Текущий E3 | Включены |
| B | Текущий E3 | Выключены |
| C | До E3: 5/2 октавы, вес 0,3 | Включены |
| D | До E3: 5/2 октавы, вес 0,3 | Выключены |

У старого шума также убирается множитель 28/31. Выключение маленьких островков
действует одновременно на запрос высоты и запись чанка через общий метод.
Кайма главного острова, биомы, хорус, города и шлюзы сохраняются. Вариант D
поэтому не равен полному откату E3.

На каждый вариант и каждое из двух исходных семян создаётся 2803 чанка Энда:
центральное окно `[-12,-12,12,12]` и внешние окна `[112,112,144,144]`,
`[-144,112,-112,144]`. Всего восемь измерений, 22424 пары чанков.
Обычный мир и Незер не включены в перепись; запуск сервера создаёт только
необходимые начальные данные обычного мира.

Официальная статистика берётся из неизменного `ci-reference-pass2.json.gz`.
Контроль A должен точно воспроизвести End-строки третьей переписи из
`end-control-pass3.json.gz`. Сами анализатор, эталон и допуски не меняются.
Строка расстояния между спавнами исключается, поскольку не относится к Энду.

Для каждого варианта отдельно сохраняются SHA коммита, исходного и изменённого
файла, описания замены, бинарника, соответствующего helper, Cargo.lock,
исходного и производного планов. Helper собирается заново из того же варианта.
Миры остаются на runner; в артефакты попадают бинарники, логи и компактные отчёты,
хранящиеся три дня. Официальный сервер и игровые архивы в опыт не входят.

Проверки перед выводами:

- Все восемь измерений содержат ровно 2803 ожидаемых чанка без пропусков.
- A воспроизводит контрольные метрики обоих семян.
- SHA высот всех 625 центральных чанков одинаков для A/B/C/D на каждом семени.
- Скачки отдельно разбиты на суша–пустота/суша–суша и границы/внутренность.
- Эффекты островков: A−B и C−D; эффекты шума: A−C и B−D. Их разница
  показывает взаимодействие факторов.
- Новые и исчезнувшие строки, новые выходы за допуск и все ухудшения
  сохраняются отдельно. Одно улучшенное число не делает вариант исправлением.

Запуск: push инструментов в `wip/end-ablation-*` запускает
`.github/workflows/end-ablation.yml`. Основная рабочая ветка при этом
не меняет алгоритм генерации. Любое будущее исправление требует обычных
Rust-проверок и отдельной сверки поведения.
