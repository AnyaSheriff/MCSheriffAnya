# Перепись генерации в GitHub Actions

Workflow `Generation census 26.3` запускает тяжёлую часть на стандартных
`ubuntu-24.04`: одна сборка, затем два независимых задания для семян owner и
second. Локальные серверы и миры пользователя ему не нужны.

Первая загрузка workflow и изменения его инструментов/эталонного пакета в
`migration/java-26.3` запускают прогон автоматически. Добавлен ручной
`workflow_dispatch`; доступность кнопки зависит от наличия workflow в основной
ветке GitHub. Изменение одного только ядра не запускает часовую перепись на
каждом коммите. Для такого повтора можно повторно запустить нужный workflow
через Actions, учитывая, что повтор задания использует исходный коммит.

## Что сравнивается

Сохраняются планы второго прохода: по 37 249 чанков обычного мира, 1089 Незера
и 2803 Энда на каждом из двух семян, всего **82 282 пары чанков**. Центры
выборки фиксированы; изменение точки появления не сдвигает сравнение.
Семена: `1792932773345722119` и `100554032945340`.

[Эталонный пакет](../testdata/world-profile/genaudit-26.3/ci-reference-pass2.json.gz)
содержит планы, полные прежние отчёты и агрегированные измерения сохранённых
официальных миров. [Происхождение и контрольные суммы](../testdata/world-profile/genaudit-26.3/ci-reference-pass2.json)
проверены по локальным исходным отчётам и манифестам миров. Самих миров,
архивов игры и учётных данных в пакете нет.

В CI заново создаются только наши миры. Неизменённые функции анализатора
сопоставляют свежие измерения с сохранённой официальной статистикой. Хеш
анализатора должен совпасть с эталонным: смена методики требует отдельного
обновления эталона. Это сравнение с ранее измеренными мирами 26.3, а не новый
запуск официального сервера.

Полное покрытие, семена, планы, коммит, бинарники и входные данные проверяются
до выдачи результата. Недостающие чанки завершают задание ошибкой. Новые и
исчезнувшие показатели учитываются отдельно; исчезнувшие не считаются
исправлениями. Все ухудшения остаются в JSON.

## Результаты и ресурсы

В Actions появляются `census-owner`, `census-second`, `census-build` и журналы
сборки. Отчёты и журналы сжаты gzip, срок хранения — три дня. Созданные миры
не выгружаются. Для долгого хранения результата нужно скачать артефакты до
истечения срока; итоговую сводку можно сохранить в документации проекта.

Workflow использует стандартные серверы, без платных увеличенных конфигураций.
Лимиты хранения артефактов действуют отдельно от бесплатного времени публичного
репозитория. Ограничение каждого задания — 90 минут. Два семени выполняются
на отдельных машинах и не нагружают ПК владельца.

Локальная проверка обёртки, без сборки и генерации:

```sh
python -m unittest discover -s tools/measure -p test_genaudit_263_ci.py
```
