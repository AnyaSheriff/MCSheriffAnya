# Вход без обязательной лицензии Java

В `config/server.properties` задайте `online-mode=false`, а в
`config/mcsa.properties` выберите один режим:

- `offline-license-mode=cosmetics`: пробовать подтвердить лицензию, получать
  официальный профиль со скином/плащом. Если проверка входа не прошла, клиент
  отключается с предложением зайти повторно без лицензии. Это ограничение
  текущего согласования шифрования; при повторном входе действует окно 5 минут.
- `offline-license-mode=disabled`: не искать лицензию по нику, не выполнять
  проверку сессии Mojang, не запрашивать профиль/скин через Mojang даже при
  `mojang=true` в `config/skins.toml`. Сохранённые скины и Ely.by остаются
  доступными; настройка не запрещает вообще все сетевые запросы сервера.

Оба режима работают независимо от `auth-enabled`. Пароли AuthMe
не отключаются: для них остаётся `auth-enabled=true`. Зарегистрированные аккаунты сохраняют свои UUID и данные.
Новый аккаунт в режиме `disabled` получает offline UUID; смена режима не
объединяет аккаунты и инвентари автоматически.

При `online-mode=true` проверка лицензии обязательна независимо от этой
настройки. Проверка Xbox Live у Bedrock задаётся отдельно.

Новый ключ имеет приоритет над старым `auth-premium`. Если нового ключа ещё
нет, `auth-premium=false` или `auth-enabled=false` переводятся в `disabled`.
При обновлении ключ дописывается в файл, существующие строки сохраняются.
После этого меняйте именно `offline-license-mode`; опечатка останавливает
запуск с пояснением, а не включает проверку незаметно.
