# FourLegacy on main (0.2.9)

- **Not yet translated or loaded:** custom chest GUIs and clan scoreboard teams are now supported; the unchanged JAR still fails the remaining API audit. No FourLegacy clan/race/ability bot proof is claimed.
- Audit: initial 2,676 diagnostics / 727 distinct reasons; previous checkpoint 2,333 / 673; previous **1,383 / 464**; current **1,057 / 371**. Exact signatures and call sites: [JSON](../tmp/fourlegacy/missing-current.json).
- Reproduce: `python3 tools/plugin-translator/translate.py tmp/fourlegacy/FourLegacy-0.1.1.jar --check-only --report tmp/fourlegacy/missing-current.json`.
- Added: real custom chest windows (9..54 slots), holders/views, cancellable open/click/drag and close events. Host transactions handle normal/right/Shift/number/offhand/double clicks, creative cloning, drag distribution, cursor return and unload cleanup. Java native views expose snapshots; writes to their top inventory are explicitly refused in Russian. Events currently cover the component's custom GUI only.
- Added: main scoreboard teams, Adventure prefixes/suffixes/colors and membership reach Java clients, including join snapshots and unload cleanup. Added `getPlayerExact`, current tick, vector/location distance/direction and nearby-player bounding boxes. Java objectives/scores and personal boards remain missing.
- Added: `newSingleThreadExecutor` / `newFixedThreadPool(1)` use one bounded FIFO per component, serviced by the host between ticks. `execute/submit`, futures, cancellation, shutdown/close are supported. Unused lambda thread factories are removed, including captured factories; arbitrary real threads remain refused in Russian.
- Added: confined File/Path/Files, bundled resources, nested YAML lists/maps/scalars and saving; all 13 embedded YAML resources match safe SnakeYAML. Tags/anchors/block strings remain unsupported. Record equals/hashCode/toString are lowered without reflection.
- Added: player inventory snapshots, stacking/removal, armor/offhand; copied item meta, names/lore, enchantments, damage/custom durability, typed PDC persisted with items. Entity/player PDC is coalesced and saved by UUID in the component's data folder, with an unload flush.
- Added: player attribute bases/modifiers with immediate projected reads and host queue mutations. Modifier keys belong to the plugin. Attributes are runtime state; some attributes, including scale, are not fully reflected in server physics. Native item extras use bounded host-issued transfer tokens.
- Added: HTTPS host declarations AND explicit admin grants, GET/POST only, bounded requests/replies/time/concurrency, pinned public DNS, no credentials/redirects/system proxies. Startup logs show each plugin's allowed hosts. [Configuration and limits](../tools/plugin-translator/README.md#разрешения-https-и-настройки-мира). A real external TLS round trip is not part of the proof.
- Added: core `monster-spawn-multiplier=1` and `ore-retention-percent=100`; defaults preserve previous behavior. Ore thinning affects newly generated chunks only. These settings do not automatically mirror FourLegacy's config.
- Missing: move/interact and other event delivery, native-container inventory events, Paper chat, scoreboard objectives, remaining entity/world/spawn and potion APIs, plugin.yml permissions; the audit is authoritative. Paper bed-rule/flight APIs remain refused by the Russian signature audit; no successful empty implementation is substituted. PlaceholderAPI remains absent; its optional type cannot be instantiated/registered.
- Existing limits: combat notifications target players; source mapping needs further verification. Damage cancellation does not undo armor wear computed earlier; death is read-only. Inventory/health reads use Java connection snapshots.
- Verification: **2,516 Rust tests passed / 69 ignored**, release build and clippy `-D warnings` passed; **47 SDK + 15 executor contracts**, record/JVM comparison, **13 YAML resources (prior checkpoint)**, **15 rejection fixtures / 3 accepted JARs** passed. [Checks](../tmp/fourlegacy/checks-current.log).
- Fixture bot on **26210** passed real chest GUI opening, holder/item delivery, cancelled and allowed clicks, cursor return, close events, scoreboard team packets, and a full core restart retaining GUI-written plugin data. It also passed join/command/Tab, item meta/PDC, attribute queue, denied HTTPS, path confinement, entity PDC after component reload, FIFO background saving, health/potions, damage modification/cancellation/death, chat/block cancellation and scheduler/config checks. Its own server stopped and its temporary directory was removed. [Bot](../tmp/fourlegacy/bot-current.log), [core](../tmp/fourlegacy/bot-core-current.log). This is a fixture proof, not a FourLegacy gameplay proof.
- Owner source/JAR, WASI isolation, auth filtering, fuel/epoch/memory limits are unchanged. No commit was made. Public API references and supported subset: [README](../tools/plugin-translator/README.md).
