# FourLegacy on main (0.2.9)

- **Rejected:** the unchanged JAR starts a real writer thread in the owner's `managers/DataManager.java` through `Executors.newSingleThreadExecutor`. This conflicts with the requested thread refusal; maps/atomics do not make that executor safe. No FourLegacy clan/race/ability bot proof is claimed.
- Audit: initial 2,676 diagnostics / 727 distinct reasons; current 2,333 / 673. Exact signatures and call sites: [JSON](../tmp/fourlegacy/missing-current.json), [initial list](../tmp/fourlegacy/missing-initial.txt).
- Reproduce: `python3 tools/plugin-translator/translate.py tmp/fourlegacy/FourLegacy-0.1.1.jar --check-only --report tmp/fourlegacy/missing-current.json`.
- Added: NamespacedKey, immutable Adventure text/colors/legacy parsing mapped to checked chat/action bar, safe maps/atomics/random/time conversions, typed health/potion mutations, optional player damage/death exports, immediate dimension-specific world borders. Existing scheduler support remains available; older components need no combat export.
- Missing: inventory/menu/PDC/meta persistence, movement/interaction, entity attackers/spawning, attributes, full YAML/resources/confined file APIs, Paper chat/scoreboards, monster multiplier/new-chunk ore percentage, Java record bootstrap support. See the exact audit for the complete list.
- Limits: damage targets are players; source mapping needs further verification. Cancellation does not undo armor wear calculated before the common damage path. Death notification is read-only; health uses the Java UI snapshot.
- Soft-dependency metadata is accepted; other Bukkit integrations are absent. PlaceholderExpansion bytecode remains explicitly unsupported. Owner source/JAR, sandbox permissions, auth filtering and fuel limits are unchanged.
- Verification: `cargo test --release`: 2,501 passed / 69 ignored; release build and clippy `-D warnings` passed; 16 key/text contracts, 15 rejection fixtures and 3 accepted JARs passed. The fixture bot on 26210 passed join/command, chat/action bar, health/potion, damage modification/cancellation, death, existing event/Tab/scheduler/config checks; its server stopped and temporary folder was removed.
