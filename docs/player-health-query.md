# Чтение живого здоровья игрока

Рабочий кандидат для игрового профиля26.3: `data get entity <игрок> Health` напрямую из консоли или Java-клиента с прежними правами `/data` (уровень4). Один target, прежние правила selector. Pos/OnGround и их execute-store сохраняются.

Разбор возвращает только план. Поручение читает сам владелец состояния после обычного применения урона в vitals; Gear/UI/сохранения не используются. Ожидания внутри player actor нет, включая self и взаимные запросы. Снимок относится к этой границе, не к промежутку между двумя соседними поручениями. Игра не делает дополнительный тик ради запроса.

Ответ связан с UUID и номером сущности текущего подключения; смена сеанса не наследует запросы. Предел64 незавершённых запросов на сервер и64 ответов на подключение, срок2с; отменённые/истёкшие чтения удаляются и из mailbox при новых запросах. При остановившемся такте возвращается таймаут. Чтение Bedrock пока явно отклоняется. Остальные поручения сохраняют порядок.

Пока только прямой Health без scale. Вложенные execute/store/function/plugin/command-block не получают разрешение на отложенный запрос и отказывают до постановки в очередь. Полная поддержка требует продолжения evaluator после асинхронного результата. Это не полный NBT/Inventory и не полная совместимость `/data`.

Original-only GitHub42986085540/sourceb5e84a4: три состояния20.0/19.5/13.375 подтверждены настоящими Health-пакетами;36 запросов с реальным execute-store+scoreboard readback. Текст20.0f/19.5f/13.375f, результат20/19/13, success1; scale2 дал40/39/26, missing-result/success0. Scale измерен для будущей реализации, в этом кандидате не включён. Независимый аудит3047проверок; это не парная проверка кандидата.

Консервативный текстовый вывод: ноль и конечные положительные значения от0.001 до10000000(не включая верхнюю границу), с суффиксомf. Крайние значения с scientific-форматом пока дают явный отказ [проверить]; не заявляется общий Java Float.toString. В продакшн допускается только после исходных тестов/Clippy/сборки и независимого просмотра результатов CI.
