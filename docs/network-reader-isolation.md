# Чтение сети при задержках мира

На тестовом VPS с двумя доступными CPU основной сетевой исполнитель имел один рабочий поток.
Если обработка игрового действия ждала синхронную блокировку мира, тот же поток
не мог обслужить читателя TCP. Уже отправленный клиентом ответ KeepAlive мог
остаться непрочитанным до истечения срока ожидания.

Читатели игровых подключений теперь работают на одном отдельном исполнителе
`mcsa-inbound-io` на весь процесс. Дубликат TCP-сокета регистрируется на этом же
исполнителе; состояние шифрования CFB8 сохраняется. Дополнительного потока на
каждого игрока нет. Тайм-ауты KeepAlive не увеличены.

Ответ KeepAlive принимается до очереди игровых действий. Остальные действия
сохраняют порядок, метку такта и разрешение обработки. Очередь каждого клиента
ограничена 4096 ещё не обработанными действиями (включая уже вынутые
для обработки) и 8 MiB учтённых данных: capacity тела пакета плюс
размер записи Incoming. Это не полный предел памяти подключения: есть буферы
сокета, декодирования и дополнительные данные старых протоколов. После
принятых действий допускается одна запись ошибки. Ошибка переполнения ставится
после уже принятых действий, не обгоняя их в очереди.

Читатель уступает исполнителю после 64 кадров либо 256 KiB декодированных тел.
Ожидание занятой блокировки переводчика 1.12.2 не блокирует читателей остальных
клиентов. Собственный пакет такого клиента всё ещё ждёт его переводчик.

Чтение больше не выполняется на игровом сетевом исполнителе. Планирование
потоков ОС и работа общего декодировщика по-прежнему влияют на задержки. Вычисления
мира, отправка чанков и плавность взрывов требуют отдельных проверок; этот
патч сам по себе не обещает 20 TPS под любой нагрузкой.

## Проверки 31 октября 2026

[Полный CI 41206441067](https://github.com/AnyaSheriff/MCSheriffAnya/actions/runs/41206441067):
исходники `47987dad9edec135efc079b31582e6de1bfd988e`, Clippy без предупреждений,
3596 тестов workspace и 3227 без default features, WASM-примеры и release build.
Сверены 12 файлов по SHA. Все 57 отслеживаемых регрессионных тестов прошли
в обоих наборах: 49 прежних и 8 новых.

Один из восьми новых тестов последовательно запускает 11 изолированных TCP-проб:
сжатие и CFB8, настоящий заблокированный World mutex, отрицательный контроль
на прежнем исполнителе, неверный и частичный ACK, FIFO/ошибки/отмена, занятый
legacy mutex и два одновременно готовых читателя. Дочерние запуски не прибавлены
к числу независимых тестов. Ещё семь тестов проверяют ограничения очереди и
освобождение ресурсов. Неудачный первый прогон сохранён: при отмене частичного
кадра Linux вернул TCP reset вместо ожидаемого тестом EOF. Исправлена проверка
закрытия, дополнительно проверяется завершение reader до разблокировки мира.

Runtime SHA256: `05c31c6161e59fcbb79d79cfbe9697a443def6df43bfebbbc0e4e9e35a83e91a`.

На VPS с двумя vCPU сделаны два ограниченных опыта на отдельных копиях одного
снимка мира, в изолированной сети с offline-наблюдателем протокола 777.
1000 TNT достигли критерия покоя без оставшихся видимых сущностей.
8000 TNT **не прошли** критерий завершения за 90 секунд: остались три видимых
TNT с новыми обновлениями состояния; дальнейшие опыты не повторялись до успеха.
Ранних отключений в обоих опытах нет, но для 8000 разрыв между серверными
пакетами достиг 14,76 секунды, а между UpdateTime — 37,19 секунды. Это не плавный
стресс-тест и не доказательство ускорения физики. Условия VPS, случайность и
реализовавшаяся цепная реакция меняются; сравнение одного прогона с другим не
устанавливает причину изменения скорости. 20 000 TNT не запускались.

[Свежая боевая проверка 41207803875](https://github.com/AnyaSheriff/MCSheriffAnya/actions/runs/41207803875)
на этом бинарнике: **15/15 сценариев, 249/0/0/0**. Инструменты закреплены
коммитом `310e97f9b6529fa3bff95ba5dd726c3b8edfe4d4`. Обе стороны записаны

анализ воспроизвёл события и сравнения. Правила сравнения и допуски не менялись.
Это проверка выбранных боевых сценариев и движения NoAI, не всего игрового процесса.
