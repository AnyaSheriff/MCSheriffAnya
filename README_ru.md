# RustCraft

[English version](README.md)

Игровой сервер, совместимый с Minecraft, написанный на Rust с нуля.

RustCraft — независимая реализация серверного протокола Java Edition. Это не
форк: сервер написан только по открытым источникам (Minecraft Wiki, описания
протокола, багтрекер) и по наблюдению за официальным сервером снаружи. В нём
нет кода Mojang, Paper, Spigot, Fabric, Forge и других ядер. RustCraft не
связан с Mojang и Microsoft и ими не одобрен.

- **Версия клиента:** Java Edition 26.1.2 (протокол 775). Старые клиенты
  заходят через ViaFabricPlus и подобные средства.
- **Стек:** Rust (edition 2024), Tokio, Serde, TOML.
- **Лицензия:** MIT.

## Что работает

- Вход в игру, несколько игроков одновременно, чат, список игроков, скины
  (Mojang, затем Ely.by как запасной источник; оба можно отключить).
- Мир хранится на диске в своём формате, сохраняется при остановке и раз в
  несколько секунд; данные и инвентарь каждого игрока — в его файле.
- Основы выживания: добыча и установка блоков, выпадение предметов, подбор,
  выброшенные предметы, падающие песок и гравий, течение воды и лавы.
- Редстоун: провод, факелы, повторители, сравнители, рычаги, кнопки,
  нажимные плиты, наблюдатели, медные лампы, лампы, двери, люки, калитки,
  поршни и липкие поршни с настоящим ходом в два такта и анимацией у
  клиента. Тайминги сверены с официальным сервером по тактам (см. ниже).
- Смена дня и ночи с солнцем, фазами луны и цветом неба; время суток
  переживает перезапуск.
- Операторы (`ops.json`), команды с уровнями прав и подсказками по Tab:
  `help`, `list`, `say`, `tp`, `gamemode`, `kick`, `give`, `clear`, `time`,
  `op`, `deop`, `setblock`, `fill`, `stop`.
- Консоль как у оригинала; техническое скрыто за `debug = true` в
  `config/rustcraft.toml`.

Пока нет: мобов, здоровья и урона, сундуков и прочих контейнеров, расчёта
освещения, сжатия пакетов, генерации мира кроме плоского.

## Запуск

```sh
cargo build
./target/debug/rustcraft
```

Чтобы вводить команды в консоль, запускайте из терминала. При первом
запуске создаются `config/`, `world/`, `logs/` и `playerdata/`. Подключайтесь
клиентом 26.1.2 к `localhost:25565`.

## Настройки

- `config/server.properties` — те же ключи и формат, что у оригинала. Ничего
  из него в код не зашито.
- `config/rustcraft.toml` — собственные настройки RustCraft (`debug`).
- `config/skins.toml` — какие источники скинов использовать.
- `ops.json` — операторы, формат оригинала.

## Сверка с оригиналом

В `tools/blackbox/` лежит «чёрный ящик»: робот заходит на официальный сервер
26.1.2 и на RustCraft, строит одну и ту же схему командами, нажимает рычаг
как игрок, записывает каждое изменение блока, действие блока и звук с
номером такта и сравнивает две записи. Официальный сервер только
запускается и наблюдается по сети, его jar не открывается. Пять сценариев
(поршень с рычагом, липкий поршень, толкание двух блоков, трава под поршнем,
повторитель с лампой) сейчас сходятся с оригиналом полностью. Подробнее —
`tools/blackbox/README.md`.

## Участие

Правила проекта, чтобы он оставался юридически чистым:

- Никакого кода игры, серверных ядер, прокси и библиотек протокола. Любая
  вики, документация, багрепорт и наблюдаемое поведение — можно.
- Настройки, которые есть в оригинальном `server.properties`, никогда не
  зашиваются в код.
- Поведение должно совпадать с оригиналом такт в такт; в сомнительных
  случаях сперва пишется сценарий для чёрного ящика.

Перед отправкой изменений: `cargo test` и `cargo clippy --all-targets`
должны быть чистыми.
