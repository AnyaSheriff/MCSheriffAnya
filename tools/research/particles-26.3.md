## Что измерено

`tools/protocol-bridge/probe_particles.py` запускает каждый официальный сервер
в отдельном временном мире на127.0.0.1:26025. JAR проверяется по SHA1:

- 775: `97ccd4c0ed3f81bbb7bfacddd1090b0c56f9bc51`;
- 777: `33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`.

По23контрольных WorldParticles: cloud, пять частиц с BlockState, dust,
dust_color_transition, entity_effect, item(red_wool×5 и sword damage7),
sculk_charge, shriek, vibration(block), trail, tinted_leaves, dragon_breath,
effect, instant_effect, flash. Для cloud отдельно count0/1/7 иforce/normal.
Все команды и исходные сетевые байты сохранены в
`tools/protocol-bridge/testdata/particle-observations.json`.

Результат: 775 отправляет Particle последним, 777 — первым. Старая скалярная
скорость соответствует трём одинаковым скоростям и randomization=0.
Количество теперь VarInt вместо i32. Остальные поля этих записей совпадают
после перевода ID. Для сравнения этих23пакетов ничего не нормализуется.

Отдельно записаны EntityMetadata облака и коровы с двумя эффектами:
serializer16 — Particle, serializer17 — массив Particle. Стандартное облако
прислало entity_effect. Попытка установить ему dust через NBT particle/Particle
не изменила результат; это НЕ доказательство настройки dust у облака. Проба
теперь не задаёт игнорируемое поле. Порядок двух эффектов коровы различается
между независимыми мирами: тест сравнивает набор цветных частиц; сам перевод
сохраняет исходный порядок, что дополнительно проверяется roundtrip.

## Исправление собственного ядра

У ItemStackTemplate поля идут **ID, count, components**, у обычного Slot —
**count, ID, components**. Реальные775байты red_wool×5: `e3 01 05 00 00`.
Наш send_particles раньше использовал порядок Slot и мог показывать другой
предмет/неправильно интерпретировать количество. Исправлено и проверяется
настоящим builder-ом ядра. Ограниченный кодек компонентов переиспользуется;
неизвестные компоненты не копируются без разбора.

## Границы

- Общие частицы с проверенными схемами переводятся в обе стороны.
- Новые777частицы и два переименованных trial_spawner-типа без подтверждённой
  эквивалентности возвращают явную ошибку. Подмена похожим эффектом отсутствует.
- Неравные скорости по осям и randomization1/2 пока не представимы старым
  пакетом; понижение возвращает ошибку.
- Проверяются конечность float/double, bool, неотрицательные count/VarInt,
  границы BlockState/item/component ID и полные границы пакета. Metadata list
  ограничен1024частицами; ItemStackTemplate поддерживает count1..127 и те же
  ограниченные компоненты, что Slot.
- [проверить] Entity-форма vibration проверена по JSON и синтетическим тестом,
  но не наблюдалась на официальном сервере. Общий перевод пакета ещё не
  доказывает одинаковое визуальное поведение всех видов частиц.
- Это часть переноса сетевых форматов. Полного игрового входа777/340 и нового
  контента26.3 пока нет; native/gameplay остаётся775.
