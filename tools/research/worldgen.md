# Генерация мира: разбор по вики

Источник: minecraft.wiki, страница `World generation`, раздел про Overworld
(плюс `Noise settings`). Здесь только конспект правил — данные, не код.
Наши шумы свои, поэтому по семени с оригиналом мы не совпадаем; повторяем
устройство: шесть параметров, уровни, таблицы биомов.

## Шесть параметров

> «Biome generation in the Overworld is based on 6 parameters: temperature,
> humidity (aka. vegetation), continentalness (aka. continents), erosion,
> weirdness (aka. ridges), and depth. Except for "depth", the other 5
> parameters are based only on horizontal coordinates.»

Температура и влажность на рельеф не влияют — только на выбор биома.

### Уровни температуры (T)

| уровень | промежуток |
|---|---|
| 0 | -1,0 … -0,45 |
| 1 | -0,45 … -0,15 |
| 2 | -0,15 … 0,2 |
| 3 | 0,2 … 0,55 |
| 4 | 0,55 … 1,0 |

### Уровни влажности (H)

| уровень | промежуток |
|---|---|
| 0 | -1,0 … -0,35 |
| 1 | -0,35 … -0,1 |
| 2 | -0,1 … 0,1 |
| 3 | 0,1 … 0,3 |
| 4 | 0,3 … 1,0 |

### Континентальность (C)

| промежуток | что это |
|---|---|
| -1,2 … -1,05 | грибные поля |
| -1,05 … -0,455 | глубокий океан |
| -0,455 … -0,19 | океан |
| -0,19 … -0,11 | побережье (Coast) |
| -0,11 … 0,03 | ближняя суша (Near-inland) |
| 0,03 … 0,3 | средняя суша (Mid-inland) |
| 0,3 … 1,0 | дальняя суша (Far-inland) |

### Уровни эрозии (E), их семь

| уровень | промежуток |
|---|---|
| 0 | -1,0 … -0,78 |
| 1 | -0,78 … -0,375 |
| 2 | -0,375 … -0,2225 |
| 3 | -0,2225 … 0,05 |
| 4 | 0,05 … 0,45 |
| 5 | 0,45 … 0,55 |
| 6 | 0,55 … 1,0 |

Высокая эрозия — ровная местность, низкая — горы.

### Странность (W) и гребни-долины (PV)

> «The PV (peaks and valleys, aka. ridges folded) value is calculated through
> the formula 1 - |(3|weirdness|) - 2|»

Уровни PV: долины (Valleys), низины (Low), середина (Mid), высоты (High),
пики (Peaks); пики — от 0,7 до 1,0.

### Глубина (depth)

> «It is roughly 0 at the surface and increases by 1/128 (0.0078125) for every
> 1 block down.»

Отделяет наземные биомы от пещерных.

## Биомы вне суши (по C и T)

Влажность, эрозия и странность здесь не участвуют.

| T | океан (C = -0,455…-0,19) | глубокий океан (C = -1,05…-0,455) |
|---|---|---|
| 0 | замёрзший океан | глубокий замёрзший океан |
| 1 | холодный океан | глубокий холодный океан |
| 2 | океан | глубокий океан |
| 3 | тёплый океан (lukewarm) | глубокий тёплый океан |
| 4 | горячий океан (warm) | он же |

При C от -1,2 до -1,05 — грибные поля, при любой температуре.

## Суша: E × PV × C

Ключевые строки таблицы (полностью — на вики):

- **Долины (Valleys)** при любой эрозии: река, а при T=0 — замёрзшая река.
  При E=6 в долинах средней и дальней суши: болото (T=1,2) или мангровое
  болото (T=3,4).
- **E=0 и E=1** — горы: снежные склоны (T<3, H=0,1), роща (T<3, H=2,3,4),
  плоскогорья при T=3,4; на пиках — зубчатые пики (T=0,1,2; W<0), замёрзшие
  пики (T=0,1,2; W>0), каменистые пики (T=3), бесплодные земли (T=4).
- **E=2, E=3** — обычная суша: средние биомы, на высотах — плоскогорья.
- **E=4** — средние биомы, у побережья пляжные.
- **E=5** — расколотые биомы (shattered) в середине, обдуваемая саванна при
  W>0 и T=2,3,4 с H=0,1,2,3.
- **E=6** — ровное: средние биомы, болота в долинах.
- Побережье при низком PV и низкой эрозии — каменистый берег (Stony Shore).

## Группы биомов

**Пляжные** — только по температуре: T=0 снежный пляж, T=1,2,3 пляж,
T=4 пустыня.

**Бесплодные (badlands)** — по влажности и странности: H=0,1 — бесплодные
земли (W<0) или размытые (W>0); H=2 — бесплодные земли; H=3,4 — лесистые.

**Средние (middle)** — основная суша, по T и H:

| H\T | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 0 | снежные равнины (W<0) / ледяные пики (W>0) | равнины (W<0) / пятнистый лес (W>0) | цветочный лес (W<0) / подсолнечные равнины (W>0) | саванна | пустыня |
| 1 | снежные равнины | равнины | равнины | саванна | пустыня |
| 2 | снежные равнины (W<0) / снежная тайга (W>0) | лес | лес | лес (W<0) / равнины (W>0) | пустыня |
| 3 | снежная тайга | тайга | берёзовый лес (W<0) / древний берёзовый (W>0) | джунгли (W<0) / редкие джунгли (W>0) | пустыня |
| 4 | тайга | древняя еловая (W<0) / древняя сосновая тайга (W>0) | тёмный лес | джунгли (W<0) / бамбуковые джунгли (W>0) | пустыня |

**Плоскогорья (plateau)** — луга, вишнёвая роща, саванновое плоскогорье,
бесплодные земли при T=4; подробная таблица на вики.

**Расколотые (shattered)** — обдуваемые холмы, обдуваемые гравийные холмы,
обдуваемый лес; при T=4 пустыня.

## Что из этого берём сейчас

Первым заходом — набор попроще, но по тем же правилам: океаны по C и T,
пляжи, реки в долинах, средние биомы по T×H, горы при низкой эрозии,
болота при E=6. Плоскогорья, расколотые и бесплодные — следом.
