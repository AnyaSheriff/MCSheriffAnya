# Таблица размещения биомов суши (вики, «World generation»)

Источник: https://minecraft.wiki/w/World_generation — раздел «inland surface
biomes» и таблицы групп (Beach, Badland, Middle, Plateau, Shattered).
Снято 2026-09-23 из исходного текста страницы (`?action=raw`). Код игры
и выгрузки из jar не использовались.

Реализовано в `biome_of` (src/world/terrain.rs) клетка в клетку; группы —
`beach`, `badlands`, `middle`, `plateau`, `shattered`, `slope`.

## Важное, чего не было в прежней сводке (worldgen.md)

- «Средние или бесплодные» (Middle при T<4, Badlands при T=4) стоят при
  эрозии 0–3 на низких и средних гребнях — отсюда бесплодные земли у моря,
  а не только на пиках.
- При эрозии 0–1 в долинах средней и дальней суши — не река, а средние или
  бесплодные биомы, выбранные как при положительной странности.
- Эрозия 5 на побережье и ближней суше: пляж (W<0), средние или обдуваемая
  саванна (W>0, T=2–4, H=0–3); на средней и дальней — раздробленные.
- Эрозия 6: в долинах и низинах — болото (T=1,2), мангры (T=3,4).
- Биом от высоты места не зависит.

## Уровни

PV = 1 − |3|W| − 2|: долины < −0.85 ≤ низкие < −0.2 ≤ средние < 0.2 ≤
высокие < 0.7 ≤ пики. Континентальность: грибы < −1.05 ≤ глубокий океан <
−0.455 ≤ океан < −0.19 ≤ побережье < −0.11 ≤ ближняя < 0.03 ≤ средняя < 0.3
≤ дальняя.
