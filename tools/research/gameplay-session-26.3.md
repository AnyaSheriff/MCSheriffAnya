# Полная тестовая сессия775→777

Работа ведётся через собственные обработчики ядра. Вход777 пока открыт только
в ignored-тесте `gameplay_probe::serve_java_26_3_probe`, который требует маркер
в отдельной рабочей папке. В обычной сборке этой точки входа нет.

## Источники и наблюдения

Схемы — закреплённые разрешённые `protocol.json`, указанные в
`tools/protocol-bridge/candidate-sources-26.3.json`. Другие реализации не читались.
Официальные серверы775/777 только исполнялись в отдельных временных папках.

`probe_effect_ids.py` проверяет SHA-1 JAR и вызывает обычную `/effect give`.
40эффектов имеют те же ID0–39. Имя `BadLuck` в JSON — команда `unluck`.
Записи обеих версий: `testdata/effect-observations.json`. Перевод всех40пакетов
проверяется побайтно в обе стороны. Флаг0x08 наблюдён на обеих версиях;
неизвестные биты вне0x0f запрещены. Бесконечная длительность−1 сохраняется.

`probe_menu_ids.py` ставит19обычных блоков, взаимодействует с ними и закрывает
полученные меню. Записи: `testdata/menu-observations.json`. Проверены сундук,
бочка, раздатчик, выбрасыватель, воронка, верстак, печь, плавильная печь,
коптильня, варочная стойка, стол зачарования, наковальня, маяк, стол картографа,
точило, ткацкий станок, кузнечный стол, камнерез и шалкеровый ящик.
Другие типы меню ещё не считаются подтверждёнными.

Данные Level Event сверены с разрешённой страницей
[Java Edition protocol/Packets](https://minecraft.wiki/w/Java_Edition_protocol/Packets):
2001 и3008 содержат BlockState, а не цвет. Оба переводятся через таблицу состояний.
Неизвестные события отклоняются. SoundEvent пока поддерживается только в форме
inline-имени; числовой реестр звуков не считается одинаковым автоматически.

## Что делает перевод

- Рецепты и книга рецептов: вложенные SlotDisplay/RecipeDisplay, ItemStackTemplate,
  IDSet, ID компонентов и динамический trim_pattern с явным контекстом.
- Достижения: перенос координат из display в конец записи777; отказ при обратном
  переводе ненулевых координат скрытого достижения, которые775 представить не может.
- Щелчки: перевод ID предметов/компонентов, ограничения числа изменённых слотов,
  проверка повторов. Хэши клиента непрозрачны и не подтверждают правильность состояния.
- Ядро рассчитывает результат действия самостоятельно и после иностранного щелчка
  пересылает контейнер с курсором. Поддельные предсказания не создают предметы.
- Абсолютная позиция775 превращается в777 position и отдельный motion, включая
  нулевой motion при остановке. Упаковка LPVec3 совпадает с родной на90векторах.
  Обратная сборка sync и stepped-доставка пока не реализованы.
- DamageEvent допускается только с известным общим реестром damage_type.

## Воспроизводимые проверки

Сначала собрать тестовый бинарник; после этого запускать `probe_session.py`
на свободном26026. Во время пробы не запускать Cargo. Скрипт создаёт временный
мир из каменной площадки, отключает AuthMe и внешний поиск скинов.

Сетевой режим проверяет вход, команды, выдачу предметов, эффект, появление моба,
время/погоду, перенос5шерсти с ложным предсказанием курсора и открытие/закрытие
сундука. `--client-dir` запускает настоящий26.3 в отдельном Xvfb с вымышленным
профилем; выполняются вход и консольные действия. Это не проверка мышью всех меню.
Переменные Wayland и пользовательского дисплея удаляются из окружения клиента.

Это подтверждает ограниченную полную сессию через настоящие обработчики,
но **не весь игровой процесс26.3**. Богатые компоненты предметов, торговля,
все metadata, новые материалы/механики и полная цепочкадо1.12.2 ещё нужны.
