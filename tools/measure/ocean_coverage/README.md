# Офлайн-перепись океанов

Тест `world::terrain::census::offline_ocean_census` не запускает сервер и
не генерирует чанки. Биомы берутся тем же `cell_biome`, что при генерации
чанка; высоты — через `column_at` с настоящей сеткой плотности. Проверка
монументов вызывает штатные `attempt` и `start_in`.

Из корня копии проекта:

```sh
CENSUS_LAYOUT=wide CARGO_TARGET_DIR=$PWD/target CARGO_NET_OFFLINE=true TMPDIR=$PWD/tmp nice -n 19 cargo test --release -j 4 offline_ocean_census -- --ignored --nocapture > tmp/ocean-wide.log
CARGO_TARGET_DIR=$PWD/target CARGO_NET_OFFLINE=true TMPDIR=$PWD/tmp nice -n 19 cargo test --release -j 4 offline_ocean_census -- --ignored --nocapture > tmp/ocean-square.log
CENSUS_LAYOUT=reference CENSUS_SEEDS=100554032945340 CARGO_TARGET_DIR=$PWD/target CARGO_NET_OFFLINE=true TMPDIR=$PWD/tmp nice -n 19 cargo test --release -j 4 offline_ocean_census -- --ignored --nocapture > tmp/ocean-reference.log
```

Во всех режимах шаг биомов 4 блока, высот — 32 блока, координаты — середины
клеток (`+2`). По умолчанию семена `100554032945340,42,1,1234567890`;
`CENSUS_SEEDS` задаёт другой список через запятую.

| Файлы до / после | Раскладка |
|---|---|
| `before.tsv`, `after.tsv` | `wide`: четыре квадрата `[-8192,8192)²`, 67 108 864 клетки |
| `before_square.tsv`, `after_square.tsv` | `square` по умолчанию: четыре квадрата `[-2048,2048)²`, 4 194 304 клетки |
| `before_reference.tsv`, `after_reference.tsv` | `reference`: одно семя, окно 2048² в нуле и восемь окон 1024² с центрами через 8192 блока, 786 432 клетки |

`before*` сняты с генератора базового коммита `a247b43` после добавления
самого измерительного теста; `after*` — после настройки континентальности
и температуры морей. Строки обвязки Cargo/libtest удалены. Цель сравнения:
`vanilla-data/biomes_vanilla_big.tsv`, сохранённая перепись vanilla 26.1.2.
Сводка и ограничения — в корневом `REPORT.md`.

## Поля TSV

- `meta`: раскладка, шаги и семена.
- `seed`: семя, число клеток, доля океана, доля глубокого океана.
- `total`: общее число клеток.
- `share`: имя биома, доля всей площади (0…1).
- `land_share`: имя биома, доля среди неокеанских клеток (включая реки).
- `summary`: доли океана, глубокого океана и неокеанских биомов.
- `height`: биом, p5/p25/p50/p75/p95 высоты, число измеренных столбцов.
- `height_group`: те же поля для `land`, `shallow`, `deep`.
- `patch`: биом, число связных пятен, медиана/p90/максимум площади в
  клетках 4×4, доля пятен размером не больше трёх клеток. `all_oceans`
  объединяет все морские типы. Соседство — по четырём сторонам; окна и
  семена не соединяются, краевые пятна усечены.
- `patch_area`: биом, взвешенные площадью p50/p90 площади пятна в блоках².
  Это размер пятна, в котором лежит случайная клетка данного биома.
- `monument`: семя, 1024 попытки, число глубоких центров, число успешных
  стартов, доля успешных стартов. Область всегда `[-16,16)²` регионов,
  независимо от раскладки переписи; на семя одна попытка в каждом регионе.

`CENSUS_CLIMATE=1` дополнительно печатает `climate_bin`: нижние границы
интервалов континентальности и температуры, умноженные на 100, число
столбцов. Это вспомогательная двумерная гистограмма на сетке высот для
подбора преобразований; в итоговые TSV она не включена.

Строки `share`, `height`, `patch` совместимы с `biome_compare.py`;
соседства `pair` этот тест не измеряет. Для совместимости `patch` использует
верхнюю медиану (`n/2`) и индекс p90 `floor((n−1)·0.9)`, как старый
`biome_census.py`; при двух пятнах этот старый формат даёт p90 ниже
медианы. В таблице сравнения REPORT приведены медиана и число пятен.
Высота описывает рельеф до
декораций: она не включает деревья и айсберги из сохранённого мира vanilla.

Независимые семена регрессии — `7,314159,987654321,-20261010`.
Тесты `ocean_distribution_and_land_relief` и
`deep_oceans_allow_monument_placement` входят в обычный `cargo test`.
