# Парные наблюдения мобов 777

574 описания — не 574 пройденных опыта. Каталог не фильтруется по поддержке нашим ядром. Будущие проверки размножения, приручения, боя и сохранения отмечены PLANNED; для них нет заявления о полноте.

Лёгкий экспорт без запуска серверов:

```
python3 -B tools/blackbox/mobs/suite.py export --output /tmp/mob-descriptions
python3 -B tools/blackbox/mobs/suite.py export --mode suite --shard 0 --output /tmp/mob-shard
python3 -B -m unittest discover -s tools/blackbox/mobs -p 'test_*.py' -v
```

Workflow `mob-blackbox-checks.yml` при push ветки запускает только 12 предварительных опытов: cow spawn/turn/teleport/tracking/damage/death, salmon spawn/damage, отрицательная поза cow, движение salmon в воде, happy_ghast с выключенным и включённым AI. После просмотра настоящих записей полный набор можно отдельно выбрать через workflow_dispatch suite=true (8 непересекающихся частей по 71–72 описания).

Нативный сервер повторно не собирается. prepare_ci.py требует успешный закреплённый run, точный HEAD, идентификатор/имя/digest артефакта, фактический SHA архива и ELF, внутреннюю source receipt. Diff от 95814d8 допускает только новые файлы этой папки и новый workflow. JAR остаётся непрозрачным; разрешённые JSON скачиваются только по закреплённым ссылкам и проверяются по размеру/SHA. Серверы работают последовательно на портах 26400+ в новых собственных мирах; локальный запуск запрещён.

`recording-status.json` отдельно показывает выполнение записи, `comparison/report.json` — совпадение поведения. Завершённая запись с DIFFERENT не является успешной проверкой совпадения. Строгий gate проваливает любой результат кроме MATCH; workflow сохраняет записи и при ошибках. В результатах остаются пакеты, команды, логи, описания, исходники нашего измерителя, pins, SHA и остановка/освобождение порта. Миры, JAR и ELF туда не загружаются; ELF представлен проверенной SHA-квитанцией. Принудительная остановка — ошибка инфраструктуры. Физические клиенты/ARM/полнота AI этими опытами не доказаны.
