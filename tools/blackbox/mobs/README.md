574 описания — не 574 пройденных опыта. Каталог не фильтруется по поддержке нашим ядром. Будущие проверки размножения, приручения, боя и сохранения отмечены PLANNED; для них нет заявления о полноте.

Лёгкий экспорт без запуска серверов:

```

python3 -B tools/blackbox/mobs/suite.py export --mode suite --shard 0 --output /tmp/mob-shard
python3 -B -m unittest discover -s tools/blackbox/mobs -p 'test_*.py' -v
```

Workflow `mob-blackbox-checks.yml` при push ветки запускает только 12 предварительных опытов: cow spawn/turn/teleport/tracking/damage/death, salmon spawn/damage, отрицательная поза cow, движение salmon в воде, happy_ghast с выключенным и включённым AI. После просмотра настоящих записей полный набор можно отдельно выбрать через push отдельной ветки test/mob-blackbox-full-20261115 (8 непересекающихся частей по 71–72 описания).

Нативный сервер повторно не собирается. prepare_ci.py требует успешный закреплённый run, точный HEAD, идентификатор/имя/digest артефакта, фактический SHA архива и ELF, внутреннюю source receipt. Diff от 0d3db6f допускает только новые файлы этой папки и новый workflow. JAR остаётся непрозрачным; разрешённые JSON скачиваются только по закреплённым ссылкам и проверяются по размеру/SHA. Серверы работают последовательно на портах 26400+ в новых собственных мирах; локальный запуск запрещён.

`recording-status.json` отдельно показывает выполнение записи, `comparison/report.json` — совпадение поведения. Завершённая запись с DIFFERENT не является успешной проверкой совпадения. Строгий gate проваливает любой результат кроме MATCH; workflow сохраняет записи и при ошибках. В результатах остаются пакеты, команды, логи, описания, исходники нашего измерителя, pins, SHA и остановка/освобождение порта. Миры, JAR и ELF туда не загружаются; ELF представлен проверенной SHA-квитанцией. Принудительная остановка — ошибка инфраструктуры. Физические клиенты/ARM/полнота AI этими опытами не доказаны.

После первой настоящей записи устранены две ошибки постановки: дальние сущности терялись в выгруженном чанке, а console say не доказывал обновления сетевого слежения при замороженном мире. Теперь один отдельный чанк x=128 удерживается загруженным для ухода/возврата и уборки; обе стороны получают одинаковые два установочных тика после summon до начального снимка. Это означает, что начальный снимок — после этих тиков, а пакет первоначального появления отдельно остаётся в ленте. Повторный GitHub-прогон должен подтвердить исправление; прежний неудачный прогон не является доказательством ошибки игры.

CI43712687277 полностью записал обе стороны: 12/12+12/12, 10 MATCH и 2 DIFFERENT (cow turn/teleport), штатная остановка обеих сторон. Эти два опыта ранее ждали только2 тика; наше слежение сверяется раз в3 тика. Следующая постановка отводит6 тиков после этих команд на обеих сторонах. Она проверяет конечное состояние за это окно и НЕ доказывает одинаковую задержку отправки пакета; исходные несовпадения сохранены, повторный результат ещё ожидается.

Текущий кандидат: проверенный main0d3db6f, CI43710307624/artifact14161281253, adaptive-43710307624-1. Его receipt не содержит job_status: успех подтверждается настоящими run/jobs через API; проверяются receipt.source, SHA каждого указанного файла и отдельный ELF SHA. Основная ветка измерителя всегда запускает только предварительные12; восемь частей запускаются исключительно для ref refs/heads/test/mob-blackbox-full-20261115. Перед следующим CI основной помощник должен объединить текущий main с веткой измерителя; иначе строгий diffgate остановит запуск.
