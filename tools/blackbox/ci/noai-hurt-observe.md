# NoAI Cow: hurt/control, только наблюдение

Закреплённый runtime: full41185482641, sourcebd47859fd86c85084790318482ff06fe25c1272e, SHA25675aec761a151872c26745d788379bce2f246b6874162364ebc9028ed1b93faca. Rust не собирается; pin не принимает override из workflow_dispatch.

Восемь новых заранее фиксированных сценариев, по одной свежей паре NoAI adult Cow в каждом, на обеих сторонах. Spawn обеих на номинальномT10; первая(3.5,0,1.5), контроль(7.5,0,1.5). Наблюдатель(3.5,0,3.5) смотрит yaw180 к первой; инвентарь и эффекты очищены, выданных предметов нет. Один обычный пакет playerattack/which0 наT110: спустя100номинальныхтактов после запланированного Spawn. Это ранее проверенный собственный путь fixedyaw; команда damage не используется. CleanupT410 — окно пары ровно400номинальныхтактов. Запись доT430 сохраняет cleanup и последнее время мира.

400тактов — планировщик recorder, не скрытое утверждение о точном внутреннем счётчике. Аудит сохраняет фактические времена Spawn, DamageEvent и каждого ambient, все UpdateTime age anchors и номинальные интервалы arrival/50ms. Доставка Spawn/атаки допускается не позже2номинальныхтактов; фактический момент hurt фиксируется отдельно. Точная длительность/константа паузы по этому допуску не объявляется.

Аудит требует: ровно две коровы по заданным позициям, исходный NoAI и отсутствие его выключения, отсутствие Silent/baby, положительное здоровье; у первой ровно один DamageEvent+hurtSound и уменьшение здоровья, у контроля ни одного и неизменное здоровье; обе доживают до конца. SourceType34 и cause/direct=selfID+1 измерены в actual777 native fixedyaw и проверяются. Это отличает принятый удар наблюдателя от случайного урона/логической строки sent без реального попадания.

Возможные velocity/movement раненой коровы сохраняются и не считаются дефектом измерения. Контроль обязан оставаться на своей позиции; ненулевые velocity/yaw/pitch/headPitch в его Spawn также запрещают валидность. Для каждой коровы сохраняются измеренные позиции из Spawn и movement-пакетов. Звук сопоставляется последней предшествующей позиции и, консервативно для sound-before-movement, ближайшей следующей позиции максимум через3номинальныхтакта (EVERY=3 собственного tracker). Большая пауза не расширяет пространственный допуск и не угадывается по скорости. Сопоставляются именно целые SoundEffect bins: floor либо trunc мировых координат×8, с неопределённостью1/4096 только для относительного движения. Произвольный звук вне этих измеренных позиций не приписывается раненой автоматически. Нет единственного совместимого владельца — unknown/ambiguous и observation-invalid; совпадение сохраняет использованные position_evidence. Полные raw и motion остаются для независимой проверки; потеря сущности до конца блокирует вывод.

Отсутствие posthurt ambient — валидное цензурированное наблюдение, поле first_voice...=null и длительность окна сохраняются. Никаких обязательных voicecount, запрета первых80/120тактов или равенства сторон нет. `observations-valid` означает только исправный фиксированный опыт, **не parity/pass combat**. Старые15combat, comparator, random-допуски и production не меняются. Strict сравнение нового опыта остаётся отдельной диагностикой; transport/decode/warnings и lifecycle failures блокируют даже валидность наблюдения.

GitHub-only wrapper использует собственный record777 и прежние проверенные preflight/buildreceipt/download/sourcehash/datahash/port/PIDcleanup/artifact guards. Серии не повторяются до успеха. Предел recorder900с, processwatchdog960с, отдельный step20мин, job24мин. Полные исходники инструментов/сценариев, протокольные таблицы, raw, strict/scoped отчёты, config/serverlogs и lifecycle архивируются, включая неудачные опыты; JAR и миры в artifact не попадают.

Локально разрешены только AST/сценарии/unit, без запуска Minecraft или Cargo. Официальный jar в GitHub только запускается, без чтения реализации/распаковки/отчётов/выгрузок реестров.
