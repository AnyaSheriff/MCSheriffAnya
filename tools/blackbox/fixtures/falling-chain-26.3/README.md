# Цепочки падающих блоков, 26.3

Исходная ветка — `82ed437`. Остановка цепочки песка не воспроизвелась:
исходный `set_block` уже передаёт изменение соседям. Исправление `fill ... strict`
позволяет построить неподвижную исходную фигуру, как у официального сервера.
Нельзя считать падение песка во время ошибочной постановки без `strict`
воспроизведением жалобы владельца.

Официальный сервер запускался последовательно на 26160 с `-Xmx3G`.
JAR не исследовался. Клиенты снимали пакеты через одинаковый внешний ViaProxy;
JSON содержит представление 775 после внешнего перевода. Манифесты сохраняют
версии, хеши бинарников и сценариев запуска. В окончательном replay оригинал
не запускался: `official_heap` в replay-манифесте — неиспользованный default,
фактический размер памяти оригинала записан в `official-manifest.json` и
`high-drop-manifest.json`.

`*-official.json.gz` — исходные сетевые записи; `*-ours.json.gz` — окончательная
сборка. `before-landing-fix-summary.json` показывает исходный результат после
исправления только `strict`: песок, гравий и пыль уже совпали, наковальни
разрывали соединение на событии 1031/0. После разрешения события выявлены
проваливание через наковальни и отсутствие износа; исправлены обе причины.
События разрушения 1029/0 и сталактита 1045/0 также подтверждены оригиналом.

Окончательно: 13/13 новых сценариев, 587 совпавших событий, без сдвигов,
пропусков и лишних событий. Три сценария наковален допускают только случайный
износ: `anvil[facing=north]` либо `chipped_anvil[facing=north]` на том же месте
и в том же такте. Это существующее правило `values` общего компаратора;
компаратор не менялся. Вероятность — вики Anvil, 5% × высота при высоте больше одного блока.
Проба с высотой 24 отдельно подтверждает все три гарантированных перехода,
включая разрушение последней ступени, без допусков.

Независимая точная проверка появлений и изменений блоков:

```sh
python3 tools/blackbox/falling_chain_audit.py tools/blackbox/fixtures/falling-chain-26.3 --output /tmp/falling-audit.json
```

Она проверяет 132 появления (такты, координаты, ID состояния) и 408 изменений
блоков. Все 12 цепочек совпали; без допуска износа полностью совпали 11/12,
с допуском только износа — 12/12. `tick-audit.json` хранит отдельные результаты.
Волны слоя: 4/8/8/4 через два такта, столб — шесть появлений через два такта,
навес — три; блок над оставшейся каменной опорой не падает.

Старые сценарии хранятся отдельно в общем `summary.json`; не все зелёные.
`brush-sand` по-прежнему разрывает соединение: неподдержанные данные
блок-сущности в мосте. Fortune-гравий: 29 совпадений и два лишних события
2019/1, как до изменений. У лесов один прогон дал девять сдвигов на один такт;
три дополнительных прогона дали 35/35; результаты сохранены отдельно, без удаления первого.
Песок в воде и сталактит совпадают полностью. Эти записи не подменяют проверку
конкретного природного нависания владельца: координаты случая неизвестны.

`verification.json`: 3352 теста прошли, 108 пропущены, строгий Clippy чист.
Первый запуск с обычной конкурентностью упал на тесте custom-tablist; полные
последующие запуски с `RUST_TEST_THREADS=2` прошли. Комментарии и документация
после проверок уточнялись без изменения исполняемого Rust-кода.
