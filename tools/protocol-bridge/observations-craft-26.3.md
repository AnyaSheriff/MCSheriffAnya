# Ручной крафт белой бетонной плиты777

Официальный сервер26.3 запускался как непрозрачный JAR с SHA1
`33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`. Никакой распаковки,
чтения кода, отчётов или выгрузок рецептов не выполнялось.

Обычные сетевые действия: открыть верстак, взять три `white_concrete`,
правой кнопкой разложить по одному в горизонтальный ряд, забрать результат.
Каждый из трёх рядов даёт **6 white_concrete_slab**. После забора все три
ингредиента исчезают; шесть плит переносятся с курсора в пустую панель.
Вертикальный столбец из трёх блоков результата не даёт; попытка забрать
пустой итог сохраняет все входы. Четыре случая прошли на официальном777.
Выбранные снимки и нажатия: [fixture](testdata/white-slab-crafting-777.json).
Это обычные пакеты, не графический клиент.

`recipe give McsaProbe minecraft:white_concrete_slab` принимает название;
сервер отвечает `No new recipes were learned`. Запись книги рецептов
по сети не декодировалась. Отсутствие рецепта в стороннем JSON не
использовалось как доказательство отсутствия рецепта.

`probe_craft_white_slab_777.py` по умолчанию показывает план. Для запуска
нужны `--run --jar <непрозрачный JAR> --data <закреплённые JSON> --output <новая папка>`.
Для нашего ядра: `--run --test-binary <testbinary> --binary-sha256 <SHA256>`
с теми же `--data` и `--output`. Порты отдельные: original26043,
privatecatalog26026; собственные конфигурации/миры. Сервер останавливается
в finally, результат содержит exit/groupgone/portfree.

Первая попытка завершилась до крафта из-за whitelist по умолчанию;
отдельная повторная запись явно отключила whitelist. Старые результаты
сохранены. Старая фиксированная сборка нашего ядра не дала результат
при трёх блоках в верхнем ряду; входы остались, сервер штатно остановился.

В реализации новый shaped-рецепт принадлежит только `Preview26_3`.
Общая таблица775 не меняется. Ручной верстак использует существующие
транзакции расхода и переноса. Автокрафтер, автозаполнение и сетевая
книга нового рецепта пока не включены; при limited crafting его результат
для выживания закрыт до реализации книги. Камнерез не проверялся.
Наличие одного рецепта не означает готовность рецептов26.3.

На исправленном тестовом бинарнике **тот же** probe прошёл4случая.
Все12снимков содержимого окна и курсора совпали с новой official04 записью;
порядок и число сетевых пакетов этим не сравнивались. Оба сервера завершились
с exit0, собственные группы исчезли и порты освободились. Старая запись
отсутствующего результата сохранена отдельно и не перезаписывалась.

Clippy с запрещёнными предупреждениями и releasebuild успешно. Исходники
во время проверок не менялись. Боевая логика в этом изменении не затрагивалась.
