# Отмена, выброс и смена рук в 26.3

Обычный официальный клиент 26.3 в отдельном Xvfb подключён к официальному
серверу через наш регистратор выбранных пакетов. Владелец теста проверяет
кадр и его SHA256 перед каждым нажатием. Номера действий получены из записи,
а результат — из состояния обеих рук и выпавших предметов.

| Действие | Родной 775 | Наблюдаемый 777 |
| --- | ---: | ---: |
| Начать копание | 0 | 0 |
| Отменить копание | 1 | 2 |
| Завершить копание | 2 | 3 |
| Выбросить стопку, Ctrl+Q | 3 | 4 |
| Выбросить один предмет, Q | 4 | 5 |
| Поменять руки, F | 6 | 7 |

Начало и завершение подтверждены предыдущей [проверкой копания](observations-dig-26.3.md).
Новая запись `testdata/actual777-player-action-observations.json` содержит выбранные
действия и подтверждения четырёх остальных случаев:

- Отпускание мыши после короткого копания обсидиана: действие 2,
  блок сохранился, руки пустые.
- Q: семь камней превратились в шесть в руке и один выброшенный предмет.
- Ctrl+Q: одиннадцать булыжников выброшены одной стопкой, рука пустая.
- F: три железных слитка и пять золотых поменялись руками без выпадения.

Все восемь кадров до/после просмотрены. Официальный сервер завершился с
кодом 0, собственные процессы остановлены, порты освобождены.
Для native775 действие 6 отдельно проверено обычным пакетным подключением
к официальному серверу: те же стопки поменялись руками.

Официальный клиент предсказывает выброс: отдельное обновление своего слота
может не прийти. Поэтому графическая проба проверяет точные количество и
имя через команды сервера для своего игрока (`SelectedItem` и
`equipment.offhand`), отдельно сохраняя последнее сетевое обновление слота.
Старые ошибки пробы сохранены: ожидание обязательного обновления слота,
неверный путь второй руки в NBT, истечение времени ручной калибровки.

## Изменения ядра и границы проверки

Перевод 775/777 использует явные именованные действия; неизвестные действия
между версиями отклоняются. Родные пакеты 775 сохраняют прежний буфер.
Отпускание использования и удар копьём проверены в отдельной
[серии наблюдений](observations-use-actions-26.3.md). Соответствие 776
не предполагается; дополнительные неизвестные действия отклоняются.
Публичный вход 777 закрыт.

Родная обработка смены рук добавлена отдельно: переставляются полные стопки
выбранного слота и второй руки, сохраняются количество и компоненты.
Повреждённый пакет, мёртвый игрок и наблюдатель не меняют инвентарь.
Использование предмета прекращается. Эти дополнительные условия покрываются
модульными тестами; их совпадение с официальной игрой ещё не измерено.

Сохранённый обсидиан сам по себе не доказывает отмену внутреннего копания:
пакет можно просто проигнорировать. Поэтому отдельный тест ядра проверяет
сброс отложенного завершения через настоящий перевод и обработчик отмены.

Проверки этой серии: 11 целевых тестов и полный набор из 2843 успешных
тестов Rust (84 пропущены), Clippy без предупреждений, release-сборка,
58 тестов Python. Исправленный тестовый бинарник прошёл четыре отдельные
сетевые пробы 777 (восемь проверок): подтверждение отмены и сохранённый
обсидиан, точный остаток/выброс 6+1 и 0+11, смена обеих рук без выпадения.
Все четыре сервера завершились с кодом 0 и освободили свои процессы/порт.

## Повторение

Из `tools/protocol-bridge`, без параллельной сборки или серверных проб:

```sh
python3 probe_actual_777_actions.py --execute \
  --jar /path/to/official777/server.jar --data /path/to/candidate-json \
  --client-dir /path/to/opaque-client-cache --output /fresh/gui-result
python3 probe_player_actions_runtime.py --execute --case swap \
  --test-binary /path/to/core-test-binary --binary-sha256 SHA256 \
  --data /path/to/candidate-json --actions testdata/actual777-player-action-observations.json \
  --output /fresh/core-result
```

Графическая проба использует 26030/26032 и требует отдельной калибровки
каждого кадра. Пакетная проба ядра использует 26026; варианты `--case`:
`cancel`, `drop_one`, `drop_stack`, `swap`. Без `--execute` сервер не запускается.
Каждая проба создаёт свой каталог и проверяет остановку своих процессов.
Бинарники запускаются непрозрачно; код, реестры и datapack не извлекаются.
