# Белая бетонная плита в камнерезе777

Официальный26.3, непрозрачный JAR SHA1
`33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c`; разрешённые закреплённые JSON.
Без исходников, распаковки, отчётов и сохранения полной таблицы рецептов.
Это обычные пакеты, не графический клиент.

Выбранная запись `declare_recipes` связала вход689 `white_concrete` с выходом
721 `white_concrete_slab`×2. Показ type5, ItemStackTemplate без компонентов,
выбранные байты `05d105020000`. Номер строки347 и ordinal0 среди рецептов
этого входа получены из настоящего пакета. Кнопка0 не предполагалась заранее:
probe считает только предшествующие записи, подходящие текущему входу.
Неподдержанная форма/тег останавливает пробу без угадывания длины.

Предположенное имя
`minecraft:white_concrete_slab_from_white_concrete_stonecutting`
подтверждено обычными `recipe take`, затем `recipe give`: сервер принял имя
и повторно отправил выбранную запись книги с результатом2плиты.

| Поле выбранной записи книги | Наблюдение |
|---|---|
| DisplayID | 1694 в этой записи, локальный номер |
| Тип | 3 stonecutter |
| Вход | SlotDisplay type6, IDSet[689] |
| Выход | type5 template, white_concrete_slab×2 |
| Станок | type4 item1513 stonecutter |
| Group raw | 0, группа отсутствует |
| Category | 10 stonecutter |
| Requirements | Some(1×IDSet[689]) |
| Flags / replace | 3 / false |

Проверены семь случаев. В открытом камнерезе положены3блока бетона.
Неверный выбор−1 до выбора рецепта сохраняет вход и пустой результат.
Правильный вычисленный выбор показывает2плиты без расхода.
Неверные−1и65536после выбора сохраняют выбранный результат и вход.
Обычный забор даёт курсор2 и уменьшает вход3→2. Курсор перенесён в панель;
Shift забирает остаток: вход и результат пусты, курсор пуст, в инвентаре
ровно6плит и нет бетона. Это проверяет расход1→2и сохранность всей пачки.

Семь проверок прошли в official01 и тем же общим repo probe в official02.
Оба сервера остановились с exit0, собственные группы исчезли,26045свободен.
[Выбранные данные](testdata/white-slab-stonecutting-777.json).

`probe_stonecut_white_slab_777.py` по умолчанию показывает план. Реальный запуск:
`--run --jar <JAR> --data <закреплённые JSON> --output <новая папка>`.
Для privatecore вместо `--jar` нужны `--test-binary <testbinary>
--binary-sha256 <SHA256>`; порт26026. Каждому запуску создаётся отдельный
мир/конфигурации; исходные записи не перезаписываются.
Числовые IDпоказов, строк и кнопок не заменяют внутреннюю идентичность рецепта.
Полный порядок пакетов, остальные рецепты и полная26.3 не проверены.

На старом фиксированном privatecore тот же probe завершился ожидаемой
ошибкой отсутствующей выбранной записи `declare_recipes`. Унаследованный
текст ошибки говорит `stone→stone_slab`, но переданные выбранные ID относятся
к белому бетону689 и новой плите721. Запись и лог сохранены; сервер exit0,
собственная группа исчезла,26026свободен. Rust этой наблюдательной работой
не менялся; результат после реализации ещё предстоит проверить.

## После реализации

Тот же probe с SHA256
`29974f924a16eca4eb66b0275314b913c4965237bc782de19c0468da05dbb703`
прошёл7случаев на новом private777catalog. Все8снимков окна/курсора
совпали с official02. Выбранный template и метаданные выбранной записи книги
также совпали после перевода IDпредметов в имена; отсутствие группы проверено.
Локальные DisplayID различаются1694/1479; ordinal кнопки вычислен из каждого
полученного пакета. Порядок всей таблицы и всех сетевых сообщений не сравнивался.

На том же бинарнике отдельно повторён прежний probe книги shaped-рецепта
(SHA256 `4149a7c7094448d3baa5ee189c35482f839766312d59c4fabf9221494ab5fde5`).
Он прошёл7случаев: все8снимков совпали с прежним official05, выбранные shaped
метаданные и ответ-подсказка также совпали после нормализации локальных ID.
Добавление камнереза не изменило эту проверенную работу верстака.

Оба наших runtime завершились с exit0, собственные группы исчезли,26026
освободился после каждого. Root выполнил полный набор2906RustPASS85ignored,
Clippy с запрещёнными предупреждениями и releasebuild на замороженных
исходниках. Это ограниченная проверка одной плиты, не готовность всего26.3;
публичный777 и постоянные миры Preview остаются закрыты.
