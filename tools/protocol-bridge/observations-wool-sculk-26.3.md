# Шерстяные плиты и скалк: выбранные наблюдения 26.3

Одинаковая сетевая проба прошла **36 случаев на ядре и официальном сервере**.
Выбранные результаты совпали. По сети проверен только белый цвет; другие
цвета покрыты внутренними тестами, но не отдельными официальными запусками.

## Что наблюдалось

В 16 опытах выполнены настоящие действия установки и разрушения в Survival.
Режим подтверждён пакетом `game_state_change` (Creative → Survival), успешное
действие — обновлением блока в нужной позиции.

| Материал | Установка | Разрушение |
| --- | --- | --- |
| Камень | Датчик активируется | Датчик активируется |
| Полная белая шерсть | Нет активации | Нет активации |
| Белая шерстяная плита | Нет активации | Нет активации |

Для плит проверены нижняя, верхняя и двойная формы, сухие и заполненные водой.
При слиянии мокрой нижней плиты результат был **сухой двойной плитой**. Это
не доказательство установки мокрой двойной плиты. Мокрая двойная форма для
отдельного разрушения задавалась командой и проверялась перед действием.

После установки наблюдение длится 3,5 с. Для разрушения — суммарно 5,5 с:
2 с между START/FINISH и ещё 3,5 с. Это ограниченное окно, не проверка точного
времени. Тихий результат принимается только при работающих каменных контролях.

Ещё 20 опытов проверяют преграду между рычагом и обычным датчиком: две линии,
на каждой воздух, камень, полная шерсть, шесть состояний плиты и опыт без
переключения рычага. Воздух, камень и все состояния плиты пропускают сигнал;
полная шерсть глушит его. Без действия сигнал отсутствует. Тихая установка
плиты, таким образом, не означает подавления проходящей через неё вибрации.

Линии между центрами блоков пересекают клетку преграды на высотах y+0,25 и
y+0,75. Это описание расположения блоков, а не измерение внутренней точки
возникновения события или доказательство алгоритма пересечения с формой.
Обычный `sculk_sensor` не имеет facing; калиброванный датчик не использовался.

## Проверка записей

На каждой стороне прошли 12 контролей и 138 запросов исходных состояний.
Ответы проверены по фактическим сообщениям `[Server]`, а не по тексту команды.
Сравниватель заново разбирает выбранные пакеты через закреплённые JSON,
проверяет позиции источника и датчика, положительную мощность активной фазы
и точные конечные имя, половину и состояние воды. Он отклонил все 9 намеренно
испорченных вариантов реальной записи ядра и неверный ожидаемый SHA ядра.

Проверяются точный SHA1 официального JAR, четыре SHA256 таблиц, одинаковый
SHA пробы и пяти её помощников, а также явно переданный SHA тестового ядра.
Официальный JAR только запускался: исходники, распаковка и выгрузки не использовались.

Записи:

- `wool-sculk-discovery-01`: первое наблюдение оригинала; [выбранные данные](observations/wool-sculk-selected.json).
- `wool-sculk-core-01`: сохранённый отказ после пяти случаев — `execute if block`
  не распознал новую плиту. Это не успешная проверка её разрушения.
- `wool-sculk-core-02` и `wool-sculk-official-01`: окончательная пара одной
  неизменённой пробой; [результаты и происхождение](observations/wool-sculk-validation.json).

Первоначальное наблюдение не подставлялось вместо свежей официальной записи.
Оба финальных сервера завершились с кодом 0, их группы процессов исчезли,
порты 26026 и 26050 освободились. Нового прогона боевых сценариев в этой серии нет.

## Воспроизведение

Без `--run` проба проверяет входные файлы и печатает план, не запуская сервер.
Для запуска нужны отдельные новые папки результатов и свободное окно без Cargo.

```sh
python tools/protocol-bridge/probe_wool_sculk_777.py --run \
  --jar /path/to/server.jar --data /path/to/pinned-json --output /new/official
python tools/protocol-bridge/probe_wool_sculk_777.py --run \
  --test-binary /path/to/core-test-binary --binary-sha256 EXPECTED_SHA256 \
  --data /path/to/pinned-json --output /new/core
python tools/protocol-bridge/compare_wool_sculk_777.py \
  /new/official/result.json /new/core/result.json \
  --expected-core-sha256 EXPECTED_SHA256 --data /path/to/pinned-json \
  --output /new/comparison.json
```

Требуется тестовый бинарник с закрытым по умолчанию профилем каталога, а не
публичный release-сервер. SHA использованного бинарника:
`f0b022197c48b72e5c8c6e342b3c7606b1917fcb2fc214cbec35d3e9b71e7026`.

Совпадение частот, точного времени, формы или порядка пакетов не заявляется.
Команда `data get ... last_vibration_frequency` записана, но её результат не
использован как доказательство частоты. Шаги, приземления, огонь, хранитель,
остальные цвета на оригинале и полный игровой процесс 26.3 этой пробой не проверены.
