## Воспроизводимый итоговый probe

[probe_wool_slab_family.py](probe_wool_slab_family.py) имеет одинаковый путь
наблюдения для оригинала и ядра. Различаются только запуск, readiness marker,
порт и обязательная проверка SHA256 core test binary. Без `--run` сервер
не запускается. Каждый реальный запуск требует нового output каталога.
Только один MC; Cargo в это время запрещён.

```bash
PYTHONDONTWRITEBYTECODE=1 python3 tools/protocol-bridge/probe_wool_slab_family.py \
  --jar /path/to/opaque-777/server.jar --data /path/to/pinned-candidate-json \
  --output /fresh/official-wool --phase both --run

PYTHONDONTWRITEBYTECODE=1 python3 tools/protocol-bridge/probe_wool_slab_family.py \
  --test-binary /path/to/hash-pinned-core-test --binary-sha256 EXACT_SHA256 \
  --data /path/to/pinned-candidate-json --output /fresh/core-wool \
  --phase both --run

PYTHONDONTWRITEBYTECODE=1 python3 tools/protocol-bridge/compare_wool_slab_family.py \
  --official /fresh/official-wool/result.json --core /fresh/core-wool/result.json \
  --data /path/to/pinned-candidate-json --output /fresh/comparison.json
```

Можно отдельно запускать `--phase recipes` и `--phase tools`; comparer принимает
список из двух result.json после `--official`/`--core`. Он требует одинаковые
runner/helper SHA для всех входов, полноценный cleanup и все16 цветов.
Проверяются одновременно независимые фиксированные ожидания выше и равенство
нормализованных выбранных результатов. Unknown/inconclusive не принимается
за воздух или отсутствие рецепта. Сопоставляются тип/число выпавших предметов,
износ, состав сетки/курсора, реальные air updates, состояния, unlock/book
metadata и отношение групп. Числовые display/group/entity/window/sequence ID
между серверами не сравниваются. Каждый drop обязан иметь положительное целое количество и ровно один свежий
SpawnEntity с тем же ID в пределах1блока от центра TARGET; число entity/размер
стопки сохраняются (наблюдалась одна entity со стопкой1/2). Итоговый comparer
проверяет общую группу внутри16wool, но не снимает concrete group в том же
сеансе; межсемейное различие выше относится к отдельным старым наблюдениям.
Нормализуется только последующий подбор своего
предмета пустой рукой; сам drop обязан совпасть по отдельному metadata.

Итоговый dual-mode official/core replay выполнен после фиксированной сборки;
его результат и хеши приведены ниже.
