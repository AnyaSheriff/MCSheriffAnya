# Карта seed MCSheriffAnya

Статическая карта **нашего** генератора, без Minecraft-сервера и без сетевых
запросов. Отображает наземные биомы, 20 категорий структур и исходную точку
появления Overworld. Есть три измерения, перетаскивание, масштаб колесом и
кнопками, координаты/биом под курсором, переход к X/Z, отдельные переключатели
структур и сохранение текущего вида в PNG. На клавиатуре: стрелки и `+`/`−`.
На сенсорном экране: перетаскивание и кнопки масштаба.

## Сборка и размещение

Из корня этой копии проекта:

```sh
./tools/seedmap/build.sh
```

Нужны Rust с `wasm32-unknown-unknown`, Python 3 и доступ к crates.io при первой
сборке. Скрипт сам устанавливает **wasm-bindgen-cli 0.2.104** внутрь
`target/seedmap-tools`, последовательно собирает WASM и создаёт
`tools/seedmap/dist/`. Все cargo-команды запускаются с `nice -n 19`, `-j 2`,
`CARGO_TARGET_DIR=$PWD/target`, `CARGO_NET_OFFLINE=false`, `TMPDIR=$PWD/tmp`.
Не запускайте другую cargo-команду одновременно.

Откройте `tools/seedmap/dist/index.html` прямо с диска или загрузите **содержимое
каталога dist** на любое статическое размещение. Достаточно трёх файлов:
`index.html`, `app.js`, `runtime.js`. Оставшиеся `seedmap.js` и
`seedmap_bg.wasm` полезны для проверок и также могут оставаться на хостинге.
Пути относительные, размещение в подкаталоге поддерживается. CDN и серверный
API не нужны. WASM встроен в `runtime.js`; Blob Worker читает его из памяти,
поэтому нет запроса `fetch` и ограничений загрузки WASM через `file://`.

Нужен современный браузер с WebAssembly, Web Worker, BigInt и Canvas 2D.
Если хостинг устанавливает строгую CSP, она должна разрешать локальные скрипты,
встроенный CSS, `worker-src blob:` и компиляцию WASM (`'wasm-unsafe-eval'`).
Политика COOP/COEP не требуется: общей памяти и потоков WASM нет.
Проверено в Chromium через `file://`; Firefox/Safari и конкретный хостинг
остаются `[проверить]`.

## Настройки и точность

* Seed — знаковое 64-битное целое. Он передаётся строкой: JavaScript не округляет
  большие значения. Текстовые названия seed здесь не преобразуются в числа.
* «Обычный» соответствует `Style::Vanilla`, «Супер плавность» — `Style::Smooth`.
  Переключатель осенних лесов должен совпадать с `autumn-forests` сервера.
  `pink-cherry-groves` меняет оформление блоков, а не карту биомов.
* Биом берётся по середине клетки 4×4 — ровно как при заполнении биомов чанка.
  Показан **наземный** слой; пещерные биомы не заменяют его на этой карте.
  В Энде цвет означает биом, а не наличие эндемняка: и над пустотой есть биомы.
* При отдалении один пиксель представляет несколько блоков. Это выборка,
  не усреднение. Для просмотра всех клеток приблизьте до шага 4 или меньше.
  Выборка ограничена примерно 1024 пикселями по каждой стороне; максимальный
  участок запроса — 32768×32768 блоков, координаты — внутри ±29000000.
* Значок обозначает **середину стартового чанка**: `chunk * 16 + 8`.
  Для клада это действительные X/Z сундука, `chunk * 16 + 9`.
  Он не показывает площадь постройки, вход или Y подземных помещений.
* Включены деревни, аванпосты, оба храма, монументы, особняки, древние города,
  камеры испытаний, stronghold, шахты, разрушенные порталы обоих миров,
  кораблекрушения, клады, руины океана и тропы, иглу, хижины, крепости Незера,
  бастионы и города Энда. Проверки биомов, высоты и исключения берутся из
  соответствующих серверных `start_in`/`site_in`/`start_at`/`city_at`.
  Например, таёжные и снежные деревни сейчас **не ставит сам сервер**, поэтому
  карта их не придумывает. Шахты проверяются по всем чанкам видимого участка.
* Спавн — исходный поиск суши Overworld. В Незере и Энде этот значок скрыт.
  Сохранённый `setworldspawn`, постройки игроков, вырезанные/необновлённые чанки,
  старые версии генератора и superflat по одному seed восстановить нельзя.
* Совпадение обещается с этой версией нашего генератора, не с ванилью и не с
  Chunkbase. Пометки `[проверить]` в существующем генераторе остаются в силе;
  карта исполняет текущее поведение даже там, где оно ещё не сверено с ванилью.

## PNG из командной строки

```sh
CARGO_TARGET_DIR=$PWD/target CARGO_NET_OFFLINE=false TMPDIR=$PWD/tmp \
  nice -n 19 cargo run --release -j 2 --bin seedmap -- \
  --seed 123 --x 0 --z 0 --radius 2048 --out map.png
```

Радиус задаётся в блоках. По умолчанию шаг 4: область 4096×4096 блоков
становится картой 1024×1024 пикселя плюс подпись и легенда. Север сверху.
В PNG нанесены все структуры и спавн, если он попадает в область.
Параметры: `--dimension overworld|nether|end`, `--smooth`, `--autumn`,
`--step N`, `--help`. Радиус 1…16384, шаг 1…1024; диаметр должен делиться
на шаг, изображение биомов — не больше 2048×2048 пикселей.

Рядом записывается `map.json`: точный seed строкой, настройки, полуоткрытые
границы `[x0,z0,x1,z1)`, спавн, все маркеры, палитра и контрольная сумма RGBA.
PNG и одноимённый JSON перезаписываются при повторном экспорте.

## Общий код и проверки

`tools/seedmap` — член workspace, библиотека `seedmap-core` (`rlib`/`cdylib`).
`src/world/seedmap_core.rs` через `#[path]` подключает **те же исходные файлы**
генератора, что и сервер. В `build.rs` только этой библиотеки включён
`cfg(seedmap_core)`: он исключает постановку блоков и игровые зависимости.
Таблицы и парсеры уже имеющихся образцов остаются прежними; карта не содержит
своих солей, правил размещения, шумов или таблиц биомов.

Маленькие общие части выделены в `gen_limits.rs`, `cave_choice.rs`,
`mineshaft_start.rs`, `spawn_search.rs`. `Terrain::biome_at` использует тот же
выбор клетки, что `column_in`, но не вычисляет ненужную для карты высоту.
Сервер сохраняет прежний путь повторного использования уже посчитанного
климата. Серверные кэши размещений сохраняются без изменения поведения.
В чистой сборке они отключены: их старые ключи содержат seed, но не стиль,
а карта может одновременно запрашивать несколько настроек одного seed.
Неизменяемые библиотеки образцов и локальные шумы по-прежнему кэшируются.

```sh
CARGO_TARGET_DIR=$PWD/target CARGO_NET_OFFLINE=false TMPDIR=$PWD/tmp \
  nice -n 19 cargo test --release -j 2 --workspace -- --test-threads=2
CARGO_TARGET_DIR=$PWD/target CARGO_NET_OFFLINE=false TMPDIR=$PWD/tmp \
  nice -n 19 cargo clippy --release -j 2 --workspace --all-targets
# После build.sh и сборки CLI; Node.js, без дополнительных npm-пакетов:
node tools/seedmap/parity-test.cjs
# Необязательно: установленный Chromium, управление через pipe, без сокетов:
node tools/seedmap/browser-test.cjs
```

Тесты сравнивают серверную и выделенную сборки на нескольких seed и
координатах, все типы структур, спавн, клетки реально сгенерированных чанков,
границы запросов и разбиение области на части. `parity-test.cjs` сравнивает
RGBA, все маркеры и спавн **реального WASM** с нативным CLI для трёх измерений,
крайних i64 seed, осенних лесов и обоих стилей; затем замеряет 4096×4096 блоков.
Сценарии vanilla black-box здесь не нужны: задача — точность относительно
нашего кода, а сам black-box в этой копии не запускается.
